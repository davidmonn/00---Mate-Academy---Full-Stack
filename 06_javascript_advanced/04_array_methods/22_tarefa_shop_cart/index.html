Aula Anterior - Array Destructuring

Tarefa: Shop cart

Intro

As compras online estão se tornando cada vez mais populares. É claro que a Loja Mate está tentando ocupar seu nicho. Nossos robôs recebem chamadas de pessoas do mundo todo, processam-nas e criam um pedido. Somos fácil de usar e usuários autorizados agora podem simplesmente enviar um SMS como uma string com o número e o tipo de produtos. Nossos robôs estão treinados para ler e compreender esses SMS. Eles precisam ser treinados... Vamos escrever a função makeOrderList, que receberá a string order e retornará um objeto no qual a chave é o produto e o valor é a quantidade do produto pedido, do tipo número. Cada elemento na order sempre começa com a quantidade do produto.

Se o nome do produto consistir em mais de uma palavra, combine as palavras no formato snake_case. Para uma string vazia, a função deve retornar um objeto vazio.

Explicação do Código:

const itens = order.split(','); Usamos o split para separar a string recebida em um array, usando a vírgula (,) como separador.

const list = {}; Criamos um objeto vazio que será preenchido com os produtos e suas respectivas quantidades.

for (let item = 0; item < itens.length; item++) Percorremos o array itens para processar cada pedido.

const currentItem = itens[item].trim(); Criamos uma variável para armazenar o item atual, removendo os espaços desnecessários no início e no final com trim().

const position = currentItem.indexOf(' '); Criamos uma variável para armazenar a posição do primeiro espaço encontrado na string usando indexOf().

const quant = Number(currentItem.slice(0, position)); Usamos slice() para pegar a parte da string que contém a quantidade, começando no índice 0 e terminando antes da posição armazenada em position. Depois, usamos Number() para converter essa string em número.

const product = currentItem.slice(position + 1).split(' ').join('_'); Usamos slice() para pegar o nome do produto a partir da posição seguinte ao espaço. Depois, split() separa as palavras em um array e join('_') junta essas palavras novamente, substituindo os espaços por _.

list[product] = quant; Por fim, adicionamos ao objeto list o produto como chave e sua quantidade como valor.
