Intro

O que é array?

Um array é uma coleção de valores armazenados em uma única variável.

Um array pode ter valores em qualquer ordem e também pode ter valores repetidos. Ex:

Cada elemento possui seu próprio índice. Por isso, mesmo que os valores se repitam, cada um terá um índice diferente.

Array vazio []

Também podemos criar arrays vazios usando colchetes sem nenhum valor dentro. Ex: const save = [];

Arrays com diferentes tipos de valores são permitidos em JavaScript e são bastante comuns.

Obtendo valores individuais

Temos algumas formas de obter valores individualmente dentro de um array:

Método split('')

Divide uma string em partes e retorna um array. Também podemos definir um separador. Ex: userName.split('');

Operador ...

Podemos criar um novo array usando colchetes [] e o operador ... seguido pelo nome da variável. Ex: [...userName];. Ele pode ser usado com uma string ou com outro array.

Método Array.from()

O Array.from() cria um novo array a partir de uma string ou de outro objeto iterável. Ex: Array.from(userName);.

Iteração

Assim como uma string, um array pode ser iterado usando um loop.
