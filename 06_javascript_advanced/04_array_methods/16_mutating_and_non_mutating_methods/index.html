Mutating and Non-mutating Methods

Intro

Agora iremos nos aprofundar em arrays e em seus metodos.

Codigo de Exemplo:

JS:

Metodos de Mutacao -> Modifica o array Original

Temos Como Exemplo:

push(), pop(), shift(), unshift(), splice(), sort(), reverse()

push()

Adiciona um ou mais valores ao final do array: Ex: result = numbers.push(100, 200, 300);

splice();

Remove, adiciona ou substitui elementos do array original a partir de um índice. Se passado dois argumentos como (2, 5), começa no índice 2 e remove 5 elementos, retornando os elementos removidos. Se feito dessa forma (2, 5, 100, 200, 300), o primeiro parâmetro indica de onde começa, o segundo indica quantos elementos serão removidos e os demais parâmetros serão inseridos dentro do array.

fill('a', 2)

Substitui os elementos do array original pelo valor passado, começando pelo índice indicado pelo segundo parâmetro. Se passarmos um terceiro parâmetro, ele indica o índice final (não incluso). Ex: ('a', 2, 5) começa no índice 2 e substitui até o índice anterior ao 5.

reverse();

Inverte a ordem dos elementos do array original. É mutável, ou seja, modifica o array original.

sort();

Ordena os elementos do array. Por padrão, compara os valores como strings, por isso não ordena números corretamente em ordem numérica. É mutável. Podemos passar uma função como parâmetro para definir como será a ordenação.

unshift()

Adiciona um ou mais elementos no inicio do array. Ex result = numbers.unshift();

pop()

Remove o ultimo elemento do array. Ex: result = numbers.pop();

shift()

Remove o primeiro elemento do array. Ex result = numbers.shift();

Métodos não mutadores → não modificam o array original; normalmente retornam um novo valor/array.

includes(3)

Mais usado principalmente para verificar se um determinado valor existe em um array.

indexOf(3)

Procura um valor e retorna o índice onde ele aparece pela primeira vez.

lastIndexOf(3)

Procura um valor e retorna o índice onde ele aparece pela ultima vez.

join('-');

Converte os elementos de um array em uma única string, usando o separador desejado.

slice(2, 5);

Copia uma parte do array e retorna um novo array, sem modificar o original. Se usado como no Ex acima (2, 5), pega os valores do indice 2 ate o indice 5.

concat(100, ['x', 'y'], 200, 300);

Cria um novo array, combinando os elementos do array original com os valores e elementos de outros arrays passados como parâmetros. Não modifica o array original.

Obs:

Só uma observação: nem todo método não mutador necessariamente retorna um novo array. includes() e indexOf(), por exemplo, retornam boolean e number.
