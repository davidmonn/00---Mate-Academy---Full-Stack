Split, join and slice methods

Intro

Agora iremos ver alguns metodos que nos ajudara a trabalharmos melhor com array

Código de Exemplo:

JS:

Método split()

Com split() podemos pegar uma string e convertê-la em um array. Podemos separar a string por letras, palavras ou por qualquer outro delimitador. Ex:

Por letras: 


const phrase = 'My name is David';
const letra = phrase.split('');
console.log(letra);

Por palavra: 


const phrase = 'My name is David';
const palavra = phrase.split(' ');
console.log(palavra);

Resumindo: o split() permite dividir uma string em partes usando um delimitador. Também podemos passar um segundo parâmetro para definir a quantidade máxima de elementos. Ex: split(' ', 3) retorna no máximo os 3 primeiros elementos.

Método join()

Usamos o join() para transformar os elementos de um array em uma string. O delimitador define como os elementos serão separados. Ex: 


const fullName = ['David', 'Monteiro'];
const separar = fullName.join(' ');
console.log(separar);

Método slice()

O slice() funciona de forma semelhante quando usado em strings. Ele permite copiar uma parte de um array sem modificar o array original. Ex: 


console.log(
  // Cria uma cópia do array inteiro
  fullName.slice(),

  // Pega todos os elementos a partir do índice 1
  fullName.slice(1),

  // Pega os elementos a partir do índice 1 até antes do último
  fullName.slice(1, -1),
);

Obs: O método slice() pode ser usado tanto em string quanto em array.

  • Array: slice() em array → retorna array
  • String: slice() em string → retorna string
