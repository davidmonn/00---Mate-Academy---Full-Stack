Tarefa: Make Robot New

Intro

A Fábrica de Robôs Mate está convidando você para se juntar à sua equipe técnica para programar robôs juntos.

Como tarefa de teste, crie uma função makeRobot que receba um name (string), wheels (número) e version (número), e retorna um objeto robô com os seguintes recursos:

  • Um getter info que retorna informações do robô no seguinte formato: 'name: %name%, chip version: %version%, wheels: %wheels%'.
  • As coordenadas devem ser armazenadas como x e y no objeto coords, com padrão de 0 para ambos.
  • Um getter location que retorna uma string com o nome e coordenadas do robô: '%name%: x=14, y=21'.
  • Métodos de movimento: goForward (y += 1), goBack, goRight e goLeft.
  • Cada método deve aceitar um parâmetro inteiro positivo step (padrão 1).
  • Os métodos de movimento devem ser encadeados como em robot.goForward().goLeft(). (Basta return this).
  • O método evacuate deve mover o robô para x: 1400, y: 500.
