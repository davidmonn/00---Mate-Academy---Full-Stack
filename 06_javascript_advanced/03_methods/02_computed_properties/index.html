Intro

Exemplo:

Para iniciar, temos um objeto chamado admin. Nele existem algumas propriedades:

Além disso, também temos uma função congratulate(), que recebe um parâmetro e imprime uma saudação:

Podemos observar que chamamos nossa função passando o objeto admin como argumento. Assim, será exibida a mensagem definida na função. 

                    
'use strict';

const admin = {
    fullName: 'David Monteiro',
}

congratulate(admin);

admin.fullName = 'Suzana Santos';

congratulate(admin);


function congratulate(user) {
    console.log(`Hi ${user.fullName}`);
}

Podemos observar que alteramos o valor da propriedade fullName do objeto.

Quando chamamos novamente congratulate(admin), a primeira chamada exibirá 'David Monteiro'. Já a segunda exibirá 'Suzana Santos', pois a propriedade foi alterada antes da segunda chamada.

Agora suponha que, em algum momento, desejamos obter apenas o primeiro nome ou o sobrenome separadamente. Para isso, adicionamos as propriedades firstName e lastName, ficando assim: 

                    
const admin = {
    fullName: 'David Monteiro',
    firstName: 'David',
    lastName: 'Monteiro',
}

Depois disso, ao alterarmos fullName, também precisamos atualizar firstName e lastName, caso contrário os valores ficarão diferentes. 

                    
admin.fullName = 'Suzana Santos';
admin.firstName = 'Suzana';
admin.lastName = 'Santos';

Para o código continuar consistente, sempre que alterarmos fullName, também precisaremos alterar firstName e lastName. Isso gera uma duplicação de dados.

Como já conhecemos firstName e lastName, podemos montar o fullName a partir deles, evitando essa duplicação.

Exemplo 01: Opção 1

A primeira opção é substituir a propriedade fullName por um método chamado getFullName(). 

                    
const admin = {
    fullName: 'David Monteiro',
    firstName: 'David',
    lastName: 'Monteiro',

    getFullName() {
        return `${this.firstName} ${this.lastName}`;
    }
}

Com isso, em vez de utilizar a propriedade fullName, passamos a utilizar o método getFullName().

O problema é que esse objeto pode estar sendo utilizado em vários lugares do código. Alterar todas essas chamadas pode dar bastante trabalho.

O ideal seria manter o código externo funcionando da mesma forma. Para isso, podemos utilizar um getter (get), que é uma propriedade de acesso.

Basta adicionar a palavra-chave get antes do nome da propriedade e criar um método que retorne o valor desejado.

Importante: um getter não recebe parâmetros. Ele é executado sempre que acessamos a propriedade fullName.

Agora o código fica assim: 

            
const admin = {
                    
    get fullName() {
        return `${this.firstName} ${this.lastName}`;
    },
                    

    firstName: 'David',
    lastName: 'Monteiro',

                    
    getFullName() {
        return `${this.firstName} ${this.lastName}`;
    }
                    
}

congratulate(admin);

// admin.fullName = 'Suzana Santos';
admin.firstName = 'Suzana';
admin.lastName = 'Santos';

congratulate(admin);

function congratulate(user) {
    console.log(`Hi ${user.fullName}`);
}

console.log(admin.firstName);

Mas como podemos voltar a utilizar uma atribuição como: // admin.fullName = 'Suzana Santos';?

Para isso, criamos um setter (set) com o mesmo nome da propriedade. Diferente do get, ele recebe um parâmetro contendo o valor atribuído, neste caso 'Suzana Santos'. 

                    
const admin = {
    get fullName() {
        return `${this.firstName} ${this.lastName}`;
    },

    
    set fullName(value) {
        const parts = value.split(' ');

        // Separamos a string em um array usando o espaço.
        this.firstName = parts[0];
        this.lastName = parts[1];
    },
    

    firstName: 'David',
    lastName: 'Monteiro',

    getFullName() {
        return `${this.firstName} ${this.lastName}`;
    }
}

Quando um objeto possui um setter, uma atribuição como admin.fullName = 'Suzana Santos' não grava esse valor diretamente. Em vez disso, o set é executado e decide o que fazer com o valor recebido, como armazená-lo ou distribuí-lo entre outras propriedades.

Resumo:

Quando criamos um objeto, podemos utilizar métodos para obter ou alterar informações. Porém, se o código já utiliza propriedades (como admin.fullName) e não queremos alterar todo o restante do projeto, podemos utilizar get e set. Assim, mantemos a mesma forma de uso da propriedade, mas podemos controlar como o valor é obtido (get) e como ele é atualizado (set).
