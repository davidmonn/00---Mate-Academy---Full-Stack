Tarefa: Pretty Array

Intro

Um belo array é um array no qual para cada número n, existe pelo menos um de n - 1 ou n + 1 em algum lugar da matriz.

Por exemplo, [2, 10, 9, 3] - é bonito, porque 2 tem 3, 10 tem 9, 9 tem 10 e 3 tem 2.

[5, 6, 7] também é bonito, porque 5 e 7 têm 6, e 6 tem 5 (e 7).

Mas [6, 7, 1] NÃO é bonito, porque 1 não tem 0 ou 2.

Escreva a função isArrayPretty que retorna true, se o array fornecido é bonito ou false se não.

Observe que um array vazio NÃO é bonito.
