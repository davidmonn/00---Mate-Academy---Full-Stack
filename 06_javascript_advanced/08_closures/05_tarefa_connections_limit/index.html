Tarefa Connections limit

Intro

O plano tarifário do provedor de serviços de internet local não contabiliza seu tráfego, mas limita o número de sessões. O usuário tem um connectionsLimit - o número de vezes que ele pode entrar na internet. Se o limite for atingido, o acesso é bloqueado.

Crie uma função makePackage que receba um número connectionsLimit e retorne uma função connect. Cada chamada connect deve retornar uma string com as informações sobre o número de sessões restantes. Se o limite for atingido, connect deve retornar a string You reached the connections limit!.

Explicando Resultado:

O que foi feito basicamente é: criamos uma function que recebe um parâmetro e, dentro dela, criamos uma nova function sem parâmetros. Essa função interna será retornada e poderá ser executada posteriormente para obtermos o resultado desejado. Nesse caso, nossa função principal recebe como parâmetro o limite de conexões.

A função interna mantém acesso às variáveis da função principal, mesmo depois que a função principal termina sua execução. Isso é o que chamamos de closure. 

function makePackage(connectionsLimit) {
  let cont = 0;

  return () => {
    const text = 'connections left';
    if (cont >= connectionsLimit) {
      return 'You reached the connections limit!';
    }
  cont++;

  return `${connectionsLimit - cont} ${text}`;

  };
}

function makePackage(connectionsLimit){}, aqui temos nossa função principal, responsável por receber o parâmetro que será passado como argumento.

let cont = 0;, criamos um contador para controlar quantas conexões já foram utilizadas. Esse contador será mantido pela função interna por meio do closure.

return () => {}, aqui criamos e retornamos uma função sem parâmetros. Essa função será armazenada em connect e poderá ser chamada posteriormente.

if (cont >= connectionsLimit), verificamos se o contador já atingiu ou ultrapassou o limite de conexões. Se isso acontecer, a função retorna a mensagem informando que o limite foi atingido.

cont++;, se o limite ainda não foi atingido, aumentamos o contador em 1. Isso acontece a cada chamada da função, permitindo controlar quantas conexões já foram utilizadas.
