Quando temos uma variavel em um bloco, essas variaveis sao armazenadas separadamente das variaveis globais (let a)

Variaveis

Em JS, uma estrutura onde temos uma chave e valor, é um objeto, e oque acontece é que para cada bloco, as variaveis que declaramos neles sao armazenados em algum tipo de objeto. E esse objeto é chamado de ambiente Lexico.

Exemplo:

Em nosso objeto interno, temos um objeto especial, onde podemos observa-lo da seguinte forma: 

// #Script = { a: 1 }
let a = 1;

if (true) {
  // #LE_1 = { b: 2 }
  let b = 2;

  if (true) {
    // #LE_2 = { c: 3}
    let c = 3;
  };

  console.log(a);
  console.log(b);
  console.log(c);
};

Quando executamos nosso codigo, todas as variaveis que seriam do bloco c nao existem, ou seja, as variaveis criadas dentro de um bloco, nao sao disponiveis fora dele.

Com isso podemos observar que no JS, o escopo de uma varaivel é limitado ao bloco no qual a variavel foi declarada. O mesmo vale para funcoes. Se declararmos uma variavel dentro de uma funcao, essa variavel nao ficara disponivel fora dessa funcao.

No entando, variaveis criadas fora de um escopo, podem ser acessadas.

Se criarmos uma variavel a palavra chave var (atualmente obsoleta), essa variavel acabara no objeto window.

Da mesma forma uma funcao, se criarmos uma funcao fora de qualquer bloco, ela tambem acabara no objeto window.

Agora se recortarmos nossa variavel var e function e a levarmos a nosso bloco c: 

let a = 1;

if (true) {
  // #LE_1 = { b: 2 }
  let b = 2;

  if (true) {
    // #LE_2 = { c: 3}
    let c = 3;

    var aa = 1;
    function aaa() {};
  };

  console.log(a);
  console.log(b);
  console.log(c);
};

A variavel declarada com var acabou no global ela nao é confinada ao bloco e isso confunde, por isso nao é mais utilizada
