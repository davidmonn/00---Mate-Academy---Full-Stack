Entendendo Melhor

Iremos comecar criando uma function chamada de sun feito isso, agora iremos criar uma const para receber nossa funcao e passar os parametos e imprimir, tudo ficando da seguinte forma: 

function sum() {

}

const result = sum(3)(5);

console.log(result);

Feito isso iremos receber o seguinte erro em nosso devTools: jscript.js:7 Uncaught TypeError: sum(...) is not a function at jscript.js:7:22

Em "sum(...) is not a function", esta nos dizendo que sum(...) nao é uma funcao. Deveria ser uma funcao pois depois dela escrevemos outro par de parenteses, ela poderia ser escrita da seguinte maneira: 

function sum() {

}


    const f = sum(3);
    const result = f(5);

// const result = sum(3)(5);

console.log(result);

Dessa forma ira ficar mais claro, agora tambem nos retornando outro erro: "Uncaught TypeError: f is not a function at jscript.js:8:16"

Oque queremos fazer com essa funcao é basicamente a soma entre 3 e 5.

Dito isso iremos agora vamos ajustar nossa function sum(), iremos comecar basicamente observando que queremos adicionar um argumento onde em nosso caso no momento tem como valor 3, entao iremos adicionar um parametro a, feito isso iremos precisar retornar (return), alguma funcao para evitar um erro.

Dentro agora de nosso retorno, iremos adicionar um novo parametro e oque desejamos que no caso é somar. Ficando da seguinte forma: 

function sum(a) {
  return (b) => a + b;
}

const f = sum(3);
const result = f(5);
// const result = sum(3)(5);

console.log(result);

Dessa forma agora teremos nosso resultado sendo 8, e se usarmos o const result = sum(3)(5) ira funcionar da mesma forma.

Em teoria uma funcao pode retornar uma referencia a si mesma.

Exemplo:

function sum(a) {
  return sum;
}

// const f = sum(3);
// const result = f(5);
const result = sum(3)(5)()();

Dessa forma podemos observar que não há nenhum erro em nosso codigo e se distuinguirmos entre chamdas com parametros e sem parametros, poderemos implementar qualquer numero de parenteses.

Em casos reais, nao é muito comum chamar uma funcao de dois parenteses, porem alguns programadores gostam de abreviar e escrevem uma linha ao inves de duas.
