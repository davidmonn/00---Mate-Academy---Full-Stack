Com esse codigo se formos em nosso navegador e abrirmos nosso DevTools (f12), podemos ir em console, onde podemos estar vendo nosso objeto. Se clicarmos na seta, o objeto ira se expandir e podemos ver seus conteudo dentro do objeto.

Com isso podemos trabalhar com ele pelo proprio console, se em nosso DevTools digitarmos user.age, iremos imprimir nosso valor atual.

Tambem podemos atribuir um novo valor com user.age++ ao fazermos isso ira ser impresso o mesmo valor, isso pois ele é imprimido antes de fazer a implementacao.

Dessa forma no estado colapsado (setinha de expandir) se o abrirmos ira nos mostrar o valor implementado, sempre que fizermos uma implementacao temos que fazer uma nova impressao do mesmo para ter seu valor mais atualizado, ja que as anteriores mostraram apenas daquele devido momento.
