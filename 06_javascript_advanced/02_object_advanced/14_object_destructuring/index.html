Object Destructuring

Intro

Agora iremos dar um olhada na funcao de clonagem que vimos anteriormente.

Explicacao

Em nossa função, iremos receber um objeto como parâmetro. Podemos criar um novo objeto e copiar todas as propriedades do objeto recebido utilizando o spread operator (...). Ex: 


function clone(source) {
    return {
        ...source,
        name: 'Bob',
        surname: 'Smith',
        partner: null,
    }
}

Podemos adicionar novas propriedades tanto antes quanto depois das propriedades copiadas.

Também podemos inserir propriedades de outros objetos utilizando o spread operator: 


function clone(source) {
    return {
        ...source,
        name: 'Bob',
        surname: 'Smith',
        partner: null,
        
        ...{ partner: 1, trabalha: 'Sim' }
        
    }
}

Como a cópia é feita seguindo a ordem em que escrevemos as propriedades, valores adicionados depois podem substituir valores anteriores com o mesmo nome. Nesse caso, partner deixará de ser null e passará a ser 1.

Caso não precisemos copiar todas as propriedades do objeto, mas apenas algumas, podemos selecionar manualmente quais queremos: 


function clone(source) {
    return {
        name: source.name,
        surname: source.surname,
    }
}

Porém, dessa forma precisamos acessar cada propriedade manualmente. Para facilitar esse processo, podemos utilizar a desestruturação (destructuring). 


function clone(source) {
    const { name: firstName, surname, age = 10 } = source;

    return {
        name: firstName,
        surname,
        age,
    };
}

A desestruturação permite extrair propriedades individuais de um objeto e armazená-las em variáveis. Podemos manter o mesmo nome da propriedade (surname), renomear uma propriedade (name: firstName) ou definir um valor padrão caso ela não exista ou seja undefined (age = 10).

Também podemos utilizar a desestruturação diretamente nos parâmetros da função: 


function clone({ name: firstName, surname, age = 10 }) {
    return {
        name: firstName,
        surname,
        age,
    };
}
