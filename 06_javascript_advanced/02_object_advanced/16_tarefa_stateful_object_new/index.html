Importante

Quando temos um array de objetos, usamos o for...of para percorrer os valores do array. Como cada valor é um objeto, podemos acessar suas propriedades. Se usássemos for...in no array, obteríamos apenas os índices (0, 1, 2...), e não os objetos.

Rascunho

eu achava que aqui estavamos criando o objeto: for (const action of actions) Porem aqui estamos passando basicamente fazendo uma forma mais simples para conseguir acessar os itens dentro do array

depois que conseguimos acessar esses valores de forma mais simples criamos um destruturing de action ou seja de cada valor pego do array ou acessado

Resumindo: primeiro acessamos os itens do array com for of depois com o destruturing podemos acessar seus valores de forma mais facil em forma de variavel.

Resumo GPT: Primeiro acessamos os objetos dentro do array usando for...of. Depois usamos o destructuring para extrair os valores dessas propriedades e trabalhar com eles através de variáveis mais simples.

O for...of e o destructuring são apenas ferramentas para chegar até os dados. A alteração acontece somente quando executamos algo que modifica o objeto, como Object.assign() ou delete.
