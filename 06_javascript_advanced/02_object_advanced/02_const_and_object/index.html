Entendimento do Resultado

Inicialmente, a variável myFriend aponta para um objeto, que podemos representar pelo endereço #1. Em seguida, a variável guest recebe esse mesmo endereço, ou seja, ambas apontam para o mesmo objeto.

Quando executamos guest.age++, o JavaScript acessa o objeto no endereço #1 e altera o valor da propriedade age.

Depois fazemos guest = null;. Com isso, apenas a variável guest deixa de apontar para o objeto, ficando sem referência para ele.

Ao executar console.log(myFriend), continuamos acessando o objeto do endereço #1, que já teve sua propriedade age alterada.

Como conseguimos alterar um objeto declarado com const?

A palavra-chave const impede que a variável myFriend receba outro valor, mas não impede a alteração dos valores que estão dentro do objeto. Como o endereço continua sendo o mesmo, podemos modificar suas propriedades normalmente.

Método Imutável

No JavaScript, existe um método chamado Object.freeze(), que impede a alteração das propriedades de um objeto. Se não quisermos que seus valores sejam modificados, podemos utilizar:
