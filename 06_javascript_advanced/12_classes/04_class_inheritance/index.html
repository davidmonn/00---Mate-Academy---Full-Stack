Class Inheritance

Intro

Aqui iremos ver sobre herança de class. Para fazermos isso, iremos entender o que é e por que ela pode ser necessária.

Código de Exemplo:

JS:

Entendendo Melhor:

Iremos criar uma class User onde ela terá as propriedades: friends, age, name e role. Em seguida, criamos um método printInfo() que imprime informações sobre esse User e o chamamos. Ficando da seguinte forma: 

class User {
  friends = [];
  age = 0;

  constructor(name, role = 'User') {
    this.name = name;
    this.role = role;
  }

  get fullName() {
    return `${this.role} ${this.name}`;
  }

  printInfo() {
    const { friends, fullName } = this;

    console.log(`${fullName} has ${friends.length} friends.`);
  }
}

const bob = new User('Bob');

bob.printInfo();

Agora iremos dar um exemplo onde temos outra classe chamada Human. Nela teremos age e name para cada pessoa. Também teremos um método celebrateBirthday(), que aumenta a idade em + 1 e retorna o nome e a nova idade. Ficando da seguinte forma: 

class Human {
  age = 0;

  constructor(name) {
    this.name = name;
  }

  celebrateBirthday() {
    this.age++;

    return console.log(`${this.name} is now ${this.age}`);
  }
}

Sabemos que User é uma pessoa, o que significa que também poderíamos usar os métodos de Human. Porém, não queremos duplicar em nosso User o que já existe em Human, como age e name. Com isso, seria interessante podermos reutilizar as propriedades e métodos que temos na classe Human.

Podemos fazer isso de uma forma muito simples. Iremos remover age e name de nosso User e usar a palavra-chave extends logo após User, seguida do nome da classe da qual queremos herdar, que é Human. Ficando da seguinte forma: 

class User extends Human {
  friends = [];

  constructor(name, role = 'User') {
    this.role = role;
  }

  get fullName() {
    return `${this.role} ${this.name}`;
  }

  printInfo() {
    const { friends, fullName } = this;

    console.log(`${fullName} has ${friends.length} friends.`);
  }
}

Feito isso, teremos um erro, pois quando uma classe possui um constructor próprio, precisamos chamar o constructor da classe pai antes de podermos usar o this. Para chamar o constructor da classe pai, usamos a palavra-chave super(). Ficando da seguinte forma: 

class User extends Human {
  friends = [];

  constructor(name, role = 'User') {
    super();
    this.role = role;
  }

  get fullName() {
    return `${this.role} ${this.name}`;
  }

  printInfo() {
    const { friends, fullName } = this;

    console.log(`${fullName} has ${friends.length} friends.`);
  }
}

Isso significa que chamamos o constructor da classe pai usando super(). Nesse caso, como não passamos nenhum argumento, o name do Human continuará como undefined.

As propriedades age e name de Human são definidas durante a execução do super(). Depois disso, o restante do constructor de User pode continuar sendo executado.

Atualmente nosso User está com name undefined. Para corrigirmos isso, iremos passar o parâmetro recebido name para o constructor da classe pai através do super(). 

class User extends Human {
  friends = [];

  constructor(name, role = 'User') {
    super(name);
    this.role = role;
  }

  get fullName() {
    return `${this.role} ${this.name}`;
  }

  printInfo() {
    const { friends, fullName } = this;

    console.log(`${fullName} has ${friends.length} friends.`);
  }
}

A herança nos permite reutilizar a lógica do constructor, propriedades e métodos da classe base.

Sintaxe

Palavra-Chave extends:

Para fazermos uma classe herdar de outra, usamos a palavra extends e escrevemos o nome da classe pai. Quando a classe filha possui seu próprio constructor, precisamos chamar o constructor da classe pai usando super() e passar os parâmetros necessários. Assim, quando chamarmos métodos como, por exemplo: 

bob.printInfo();
bob.celebrateBirthday();

O objeto bob poderá acessar tanto os métodos definidos em User quanto os métodos herdados de Human. A cadeia de prototypes será semelhante a: 

bob
  ↓
User.prototype
  ↓
Human.prototype
  ↓
Object.prototype

Testando Métodos Padrão

Aqui iremos realizar alguns testes com métodos padrão, ou seja, métodos que já estão disponíveis por meio do prototype.

hasOwnProperty('name')

Aqui iremos testar o hasOwnProperty('name'). Estamos especificando o nome da propriedade, nesse caso name, e verificando se o próprio objeto possui uma propriedade com esse nome: 

console.log(
    bob.hasOwnProperty('name')
);

Teremos como resultado true, pois name é uma propriedade que existe diretamente no objeto bob.

Chamando Métodos da Classe Pai

Além do constructor da classe pai, podemos usar super para chamar métodos da classe pai. Por exemplo: iremos chamar o método celebrateBirthday() além do printInfo(). Para isso, podemos ir em nosso método printInfo() da classe User e adicionar a chamada do celebrateBirthday(), ficando da seguinte forma: 

class User extends Human {
  friends = [];

  constructor(name, role = 'User') {
    super(name);
    this.role = role;
  }

  get fullName() {
    return `${this.role} ${this.name}`;
  }

  printInfo() {
    const { friends, fullName } = this;

    console.log(`${fullName} has ${friends.length} friends.`);
    this.celebrateBirthday();
  }
}

Agora iremos supor que nossa classe pai também tenha um método printInfo(), mas que funcione de forma um pouco diferente: 

class Human {
  age = 0;

  constructor(name) {
    this.name = name;
  }

  celebrateBirthday() {
    this.age++;

    return console.log(`${this.name} is now ${this.age}`);
  }

  
    printInfo() {
        const { age, name } = this;
        console.log(`${name} is ${age}`);
    }
  
}

Se quisermos agora usar esse novo método na classe filha, voltamos novamente ao printInfo() de nosso User. Se usarmos this.printInfo(), estaremos chamando o próprio método printInfo() de User novamente, causando uma recursão, pois o método chamará a si mesmo.

Nesse caso, queremos chamar o método printInfo() da classe pai. Para isso, também usamos a palavra-chave super, ficando super.printInfo();. Dessa forma, estamos chamando o método printInfo() da classe pai. Ficará da seguinte forma em nosso código: 

class User extends Human {
  friends = [];

  constructor(name, role = 'User') {
    super(name);
    this.role = role;
  }

  get fullName() {
    return `${this.role} ${this.name}`;
  }

  printInfo() {
    const { friends, fullName } = this;
    super.printInfo();

    console.log(`${fullName} has ${friends.length} friends.`);
  }
}

Nesse caso, primeiro será chamado nosso printInfo() da classe pai. Depois, será executado o console.log() da classe filha. Também podemos alterar a ordem. Para isso, basta colocarmos o super.printInfo() abaixo de nosso console.log().

Entendimentos:

Se apagarmos nossos logs e deixarmos apenas: 

console.log(bob);

Podemos ver um objeto possuindo age, name, friends e role. Não aparecem apenas as propriedades que adicionamos diretamente na classe User, mas também as propriedades adicionadas ao objeto durante a execução do constructor da classe base Human. Isso acontece porque o super(name) executa o constructor de Human, que adiciona name ao objeto.

Em seguida, também podemos observar a cadeia de prototype, que permite que o objeto encontre métodos que não estão diretamente dentro dele.

Podemos ver que temos o método printInfo() e o getter fullName disponíveis por meio do prototype da classe User.

Também podemos ver outro prototype, relacionado à classe Human. Isso acontece porque User herda de Human. Dessa forma, caso um método não seja encontrado no User.prototype, a busca continua no Human.prototype e depois no Object.prototype.

Observando como a Herança é Implementada no Navegador

Primeiro iremos limpar tudo em nosso devTools. Para isso, basta clicarmos onde está sendo indicado:

Após isso, iremos digitar em nosso devTools: document.body. Dessa forma, o navegador irá mostrar o elemento. Porém, queremos visualizar esse elemento como um objeto. Então iremos escrever console.dir(document.body).

Agora veremos o elemento como um objeto e poderemos observar sua cadeia de prototype.

Podemos observar seu constructor sendo HTMLBodyElement. Se expandirmos, veremos diversas propriedades e métodos. Ao descermos mais, poderemos observar que HTMLBodyElement possui um prototype relacionado a HTMLElement.

Descendo ainda mais, veremos outro prototype, relacionado a Element. Element representa elementos do DOM e fornece propriedades e métodos que podem ser utilizados por diferentes tipos de elementos, incluindo elementos HTML e SVG.

Descendo ainda mais, veremos que Element está relacionado a Node. Node é uma base mais geral do DOM e pode representar diferentes tipos de nós, como elementos, textos e comentários.

E essa cadeia continua até chegar a Object.prototype.
