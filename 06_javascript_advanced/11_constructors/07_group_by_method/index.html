Tarefa: Group by method

Intro

Crie um novo método de array groupBy que receba um callback e o execute para cada elemento e retorne um objeto com resultados de callback como chaves e array de elementos que fornecem este resultado como valores.

Se callback não for passado, use x => x

Explicação do Código:

1) Podemos observar que temos 3 objetos. Criamos também o último (const robots), que utiliza as referências dos outros 3 objetos para podermos percorrê-los através do nosso método criado.

2) Criamos a função groupByMethod(). Ela não possui parâmetros, pois sua função é ser executada quando for chamada para criar o nosso método groupBy.

3) Array.prototype.groupBy = function(callback = x => x). Essa parte é muito importante. Primeiro, acessamos o Array, depois acessamos seu prototype. Dentro dele, estamos criando o método groupBy, que recebe uma função como parâmetro chamada callback. Caso nenhum callback seja passado, será utilizada por padrão a função x => x.

4) Criamos uma variável chamada result e iniciamos ela com um objeto vazio para podermos armazenar os grupos que serão criados.

5) Usamos o for...of, pois queremos acessar cada elemento do array. A variável value receberá cada elemento durante a iteração, enquanto this representa o array que chamou o método groupBy.

6) const save = callback(value); Aqui criamos uma variável chamada save para receber o resultado que o nosso callback retorna para cada elemento da iteração.

7) Outra parte importante: if (!result[save]). Primeiro verificamos se já existe uma propriedade em result com o nome que está dentro de save. Caso não exista, result[save] terá o valor undefined, que é considerado falsy. O ! inverte esse valor, fazendo com que !undefined seja true, permitindo que entremos na condicional.

8) result[save] = []; Aqui estamos criando uma propriedade dentro de result usando o valor de save como nome da propriedade, e atribuindo a ela um array vazio.

9) result[save].push(value); Aqui estamos acessando o array que foi criado dentro de result[save] e usando o .push() para adicionar o elemento atual (value) a esse grupo.
