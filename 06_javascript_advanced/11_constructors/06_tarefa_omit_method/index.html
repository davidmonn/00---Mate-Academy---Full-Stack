Tarefa: Omit method

Intro

Esta seção será dedicada à extensão de protótipos padrão com métodos que podem ser úteis para você no futuro e para a criação de seus próprios construtores.

É uma situação comum que o objeto com o qual estamos trabalhando contenha informações redundantes. Precisamos obter uma cópia dele, mas sem chaves extras.

Adicione o método omit ao protótipo dos objetos, que pega um array de chaves e retorna um novo objeto sem as chaves especificadas.

Explicação da Tarefa:

Basicamente, o que foi pedido é criar um novo objeto usando o método omit, ignorando as propriedades que forem passadas no array de chaves.

Detalhes do código:

1) Aqui estamos acessando o prototype de Object e adicionando uma nova propriedade chamada omit. O valor dessa propriedade é uma função. 

1) Object.prototype.omit = function omit(keys)

2) Aqui iremos armazenar o novo objeto que será retornado pelo método. 

2) const newInfs = {};

3) Estamos usando o for...in para percorrer as propriedades de this. O this representa o objeto que chamou o método omit. 

3) for (const value in this)

4) Aqui estamos adicionando uma condição. Usamos o Object.hasOwn(), pois como estamos lendo as propriedades com o for...in, a função omit também poderá ser encontrada. Isso acontece porque, ao fazer Object.prototype.omit = function, adicionamos omit como uma propriedade do Object.prototype.

Se não usarmos o hasOwn(), essa propriedade herdada do prototype também será iterada pelo for...in. O hasOwn() serve para verificarmos se a propriedade pertence diretamente ao objeto que estamos percorrendo, e não ao seu prototype.

Por fim, nosso !keys.includes(value) verifica se a propriedade atual não está entre as propriedades que queremos ignorar. 

4) if (Object.hasOwn(this, value) && !keys.includes(value))

5) Aqui copiamos a propriedade para o novo objeto. value representa o nome da propriedade e this[value] representa o valor dessa propriedade. 

5) newInfs[value] = this[value];
