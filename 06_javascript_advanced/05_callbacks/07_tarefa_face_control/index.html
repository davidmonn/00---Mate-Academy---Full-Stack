Tarefa: Face control

Intro

Robô, robô, robô, cachorro, robô... Pare. Cachorro? Quem deixou o cachorro entrar aqui? Como você pode ver, a proteção da Fábrica de Robôs Mate funciona com muito esforço. Mas esses processos precisam ser automatizados.

Vamos escrever uma função processArray que aceita um array items e uma função callback. Execute o callback para cada elemento de items e substitua o elemento pelo resultado do callback. Você não precisa retornar nada, apenas alterar o array items.

Explicacao processArray

Começamos com uma função que recebe dois parâmetros: items, que é o array de objetos, e callback, que é a função que será executada para cada elemento.

Fazemos a iteração de items com um loop for. A cada repetição, acessamos items[i] para pegar o objeto atual e passá-lo para o callback.

O resultado retornado pelo callback substitui o elemento atual do array através de items[i] = callback(items[i]).

Explicacao isRobot()

Essa função recebe um objeto como parâmetro para fazer uma verificação com a condicional if. Usamos robot.type para acessar o valor da propriedade type e verificar se ele é igual a 'robot'.

Se for igual, retornamos true. Caso contrário, retornamos false.
