Tarefa: Format message

Intro

Crie uma função formatMessage que receba uma string message e uma função callback. Chame o callback para cada palavra na message, junte os resultados em uma nova string e retorne-a.

Explicação formatMessage

Criamos uma função formatMessage() que recebe dois parâmetros: message, que contém a string, e callback, que recebe uma função.

Como nossa variável é uma string, primeiro a convertemos em um array para podermos percorrer cada palavra com o loop. Fazemos isso com save = message.split(' '), separando as palavras pelos espaços. Dessa forma, temos save = ['Teste', 'de', 'words'].

Em seguida, criamos armz = [] para armazenar os resultados. Dentro do loop, usamos callback(save[i]), que executa a função recebida como callback passando a palavra atual como argumento. O resultado retornado pelo callback é então armazenado em armz.

Por fim, usamos return armz.join(' ') para juntar os elementos do array novamente em uma string, separados por espaços.
