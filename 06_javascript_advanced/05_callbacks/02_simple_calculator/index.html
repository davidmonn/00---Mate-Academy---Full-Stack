Tarefa: Simple calculator

Intro

Escreva a função calculate, que recebe um array operands com 2 números e uma função de retorno de chamada operation que trabalha com 2 números. calculate deve retornar o resultado da chamada da operation com os números de operands.

Resultado

JS:

Explicacao Resultado:

1) Criamos a funcao calculate recebendo dois parametros: o primeiro para o array e o segundo para a operacao.

2) Em seguida, fazemos uma desestruturacao do nosso array para separar os dois valores e podermos realizar a operacao com eles.

3) Por ultimo, retornamos a chamada da funcao operation, passando a e b como argumentos. 


function calculate(operands, operation) {
  const [a, b] = operands;

  return operation(a, b);
}

1) Criamos uma nova funcao com dois parametros para receber os dois valores enviados pela funcao calculate.

Fazemos um retorno com a operacao entre a e b. 


function sum(a, b) {
  return a + b;
}

Por fim, chamamos a funcao calculate, passando o array test e a funcao sum. 


let teste = calculate(test, sum);

Tambem podemos utilizar uma arrow function para criar uma nova operacao diretamente dentro da chamada, sem precisar criar uma funcao separada. 


let testee = calculate(test, (a, b) => a - b);
