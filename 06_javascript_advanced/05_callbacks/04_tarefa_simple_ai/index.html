Tarefa: Simple AI

Intro

No processo do Mate Grand Hotel, após a construção do 5º prédio, houve muita rotina. Decidiu-se construir uma inteligência artificial simples que, com base nos dados primários sobre o cliente, decidiria o que oferecer a ele.

Crie uma função offerRoom que receba 3 callbacks:

  • getClientStatus
  • offerStandardRoom
  • offerLuxuriousRoom

Se getClientStatus retornar a string vip - retorne a chamada para offerLuxuriousRoom, caso contrário, recomende um quarto simples (chame offerStandardRoom).
