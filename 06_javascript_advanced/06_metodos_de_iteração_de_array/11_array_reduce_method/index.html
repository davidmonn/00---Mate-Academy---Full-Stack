Tarefa: Array Reduce Method

Intro

Implemente o método reduce, que repete a funcionalidade do método original. Use o método interno this para acessar o array.

O uso de métodos Array é proibido nesta tarefa. Use loops, acesso ao índice e comprimento do array, se necessário.

Explicação Código:

Primeiro, iniciamos criando nossa function com dois parâmetros:

numbers.reduce = function(callback, inf){}

O callback é a função que será executada em cada elemento, enquanto inf representa o valor inicial do acumulador.

Após isso, criamos duas variáveis: let start = inf; e let startIndex = 0;.

O motivo para criarmos as duas é:

let start = inf; serve para termos uma variável própria para armazenar e atualizar o acumulador, sem alterar diretamente o parâmetro inf.

let startIndex = 0; serve para controlarmos em qual índice o nosso for deve começar. Isso será importante quando não for passado um valor inicial. 

if (inf === undefined) {
start = this[0];
startIndex = 1;
}

Essa condicional verifica se o valor de inf é undefined.

Se for undefined, usamos o primeiro elemento do array como nosso acumulador inicial. Por isso fazemos: start = this[0].

Como o primeiro elemento já foi usado como acumulador, precisamos começar a iteração pelo índice 1. Por isso fazemos: startIndex = 1.

Dessa forma, evitamos processar o primeiro elemento novamente.

for (let i = startIndex; i < this.length; i++) {}

Fazemos com que i = startIndex para que o início da nossa iteração dependa da situação.

Se foi passado um valor inicial, startIndex continua sendo 0, então percorremos todos os elementos.

Se não foi passado um valor inicial, startIndex passa a ser 1, pois o primeiro elemento já foi usado como acumulador.

start = callback(start, this[i], i, this);

Aqui executamos o callback passando:

  • start → acumulador atual;
  • this[i] → elemento atual;
  • i → índice atual;
  • this → o array inteiro.

O resultado retornado pelo callback passa a ser o novo valor de start.

Dessa forma, o resultado de uma iteração é usado como acumulador na próxima, até chegarmos ao resultado final.
