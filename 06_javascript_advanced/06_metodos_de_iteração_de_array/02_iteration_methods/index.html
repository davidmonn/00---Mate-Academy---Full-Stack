Iteration Methods

Intro

Anteriormente vimos sobre o metodo forEach que recebe um callback itera sobre o array e para cada elemento chama o callback, passando o elemento, indice e referencia ao array inteiro.

Codigo de Exemplo:

Aqui iremos continuar basicamente com nosso mesmo codigo da aula anterior, fazendo algumas modificacoes para poder compreender melhor: 

const words = ['one', 'two', 'three', 'four', 'five', 'six'];

function forEach(callback) {
  for (let i = 0; i < this.length; i++) {
    callback(this[i], i, this);
  }
}

const result = words.forEach((item, index) => {

  return word.length;

Metodo map(function(parametro) => {condicao})

Com map, podemos transformar cada elemento de um array e guardar os resultados em um novo array, mantendo o array original intacto. Porém, se os elementos forem objetos, precisamos tomar cuidado, pois o map não cria automaticamente uma cópia dos objetos. 

const result = words.map((word, index) => {
    console.log(word, index);

    return word.length;
})
             
                
const result = words.map((word, index) => word.length + index);

Unica mudanca que temos no codigo acima é que temos o mesmo resultado porem de forma que a sintaxe ficou abreviada (arrow function).

Metodo filter(function(parametro) => {condicao})

Retorna um novo array, contendo apenas os elementos dos quais a funcao retornou algo equivalente a verdadeiro. Ex: 

words.filter((word, index, items) => word.length > 3);

Ou

const result = words.filter((word, index, items) => {
  return word.length > 3;
});

Ambos sao a mesma coisa, mudando apenas sintaxe.

Método find(function(parametro) {condição})

Ele retorna o primeiro elemento do array cujo callback retorna algo equivalente a verdadeiro. Se nenhum elemento atender à condição, retorna undefined. Também temos o findIndex(), que funciona de forma semelhante, mas retorna o índice do primeiro elemento encontrado. Por padrão, retorna -1 caso nenhum elemento atenda ao nosso critério. 

const result = words.find((word, index, item) => word.length > 3);

Ou

const result = words.findIndex((word, index, items) => {
   console.log(word);
  
  
   return word.length > 3
 })

Método some(() => {})

Retorna true se pelo menos um elemento do array atender à condição definida no callback. Caso nenhum elemento atenda à condição, retorna false. Se o array estiver vazio, o método some também sempre retornará false, pois não existe nenhum elemento que possa atender à condição. 

const result = words.some((word, index, items) => {
  console.log(word);
  
  return word.length >= 5
});

Ou

const result = words.some((word, index, items) => word.length >= 5);

Método every(() => {})

Retorna true somente se todos os elementos do array atenderem à condição definida no callback. Se pelo menos um elemento não atender à condição, retorna false. Caso o array esteja vazio, o método every retorna true. 

const result = words.every((word, index, items) => word.length > 2);

Ou

const result = words.every((word, index, items) => {
    return word.length > 2;
})

Analogia de Exemplo Basico

every → como uma senha que precisa passar por todas as verificações. Se uma falhar → false.

some → como um filtro de busca: basta uma opção atender ao critério → true.

Explicando algumas partes nao usadas do Codigo

word → elemento atual

index → índice do elemento

items → array original
