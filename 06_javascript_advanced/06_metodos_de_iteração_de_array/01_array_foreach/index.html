Array forEach

Intro

Aqui iremos entender o método forEach() e como ele trabalha com callbacks.

Também iremos criar nosso próprio método chamado runForEach(), utilizando um for no lugar do forEach().

Código de exemplo

Primeiro temos um array:

const words = ['one', 'two', 'three', 'four', 'five', 'six'];

Normalmente poderíamos utilizar o forEach():

words.forEach((item, index, items) => {
    console.log(item, index, items);
});

O forEach() percorre cada elemento do array e executa o callback uma vez para cada elemento.

1. Criando nosso próprio método

Para entender melhor o funcionamento, iremos criar um método chamado runForEach(). 

words.runForEach();

Esse método ainda não existe. Então precisamos criá-lo:

words.runForEach = function(callback) {

};

Estamos adicionando uma função chamada runForEach ao nosso array.

Essa função recebe um parâmetro chamado callback.

Quando fizermos:

words.runForEach((item) => {
    console.log(item);
});

A função que está sendo passada para runForEach() será recebida pelo parâmetro callback.

2. Por que usamos uma função regular?

Nosso método será criado utilizando uma função regular: 

words.runForEach = function(callback) {

};

Isso é importante porque iremos utilizar a palavra-chave this.

Quando fazemos:

words.runForEach();

O this, dentro dessa função, representa o objeto que chamou o método. 

this === words

Portanto, dentro do nosso método, podemos utilizar:

this.length
this[i]

Como this representa nosso array words, this.length representa o tamanho do array e this[i] acessa um elemento através do seu índice.

3. Percorrendo o array

Agora precisamos fazer nosso método percorrer todos os elementos do array.

Para isso utilizaremos um for:

for (let i = 0; i < this.length; i++) {

}

Como this representa words, o for irá percorrer os índices do array. 

i = 0 → this[0] → 'one'
i = 1 → this[1] → 'two'
i = 2 → this[2] → 'three'
i = 3 → this[3] → 'four'
i = 4 → this[4] → 'five'
i = 5 → this[5] → 'six'

Até aqui, nosso for simplesmente está percorrendo o array.

4. Executando o callback

Agora precisamos fazer algo em cada volta do for.

O nosso callback está armazenado na variável callback.

Para executar uma função armazenada em uma variável, podemos utilizar: 

callback();

Porém, queremos enviar o elemento atual para o callback. O elemento atual está em: 

this[i]

Então fazemos:

callback(this[i]);

Agora, a cada volta do for, o elemento atual será enviado para o callback. 

i = 0
this[i] → 'one'
callback('one')

i = 1
this[i] → 'two'
callback('two')

i = 2
this[i] → 'three'
callback('three')

5. Passando item, index e array

O forEach() pode passar três informações para o callback: 

item
index
array

Podemos fazer a mesma coisa no nosso método:

callback(this[i], i, this);

Cada informação possui uma função:

this[i] → elemento atual
i       → índice atual
this    → array completo

Portanto:

callback(this[i], i, this);

será recebido pelo callback desta forma:

(item, index, items)

Por exemplo, quando i for 2:

this[i] → 'three'
i       → 2
this    → ['one', 'two', 'three', 'four', 'five', 'six']

Então será equivalente a:

callback(
    'three',
    2,
    words
);

6. Nosso método completo

Agora podemos juntar todas as partes:

words.runForEach = function(callback) {

    for (let i = 0; i < this.length; i++) {

        callback(this[i], i, this);

    }

};

7. Utilizando nosso método

Agora podemos utilizar o método que criamos:

words.runForEach((item, index, items) => {

    console.log(item, index, items);

});

O funcionamento será:

runForEach()
      ↓
recebe o callback
      ↓
inicia o for
      ↓
pega o elemento atual
      ↓
executa o callback
      ↓
passa para o próximo elemento
      ↓
executa o callback novamente
      ↓
continua até o final do array

8. A ideia principal

Podemos resumir nosso método em três partes:

for
↓
percorre o array


callback
↓
executa uma função para cada elemento


this[i]
↓
pega o elemento atual

Portanto, a lógica principal do forEach() pode ser entendida como: 

percorrer o array
        +
executar o callback
        +
entregar o elemento atual

9. Código completo

'use strict';

const words = ['one', 'two', 'three', 'four', 'five', 'six'];

words.runForEach = function(callback) {

    for (let i = 0; i < this.length; i++) {

        callback(this[i], i, this);

    }

};

words.runForEach((item, index, items) => {

    console.log(item, index, items);

});

10. Observação sobre o retorno

O forEach() não cria um novo array e não retorna o resultado do callback.

Por isso, quando fazemos:

const result = words.forEach(...);

console.log(result);

O resultado será:

undefined

Isso acontece porque a função apenas percorre o array e executa o callback.
