Tarefa: Link and URLs

Intro

Resolva a tarefa:

  • Use o cabeçalho de navegação que você fez na lição Block, inline and inline-block
  • Use a página com 4 seções da lição Responsiveness basics (e adicione um atributo id para cada seção: section-1, section-2, section-3, section-4)
  • Os links no .header devem proporcionar uma navegação suave pela página (use seções id)
  • A seção para a qual mudamos deve ser destacada
  • Adicione um link para retornar ao topo da página em cada seção
  • Estilize todos os estados necessários para os links de navegação (:link,:visited, :hover,:active)
  • Adicione uma linha horizontal de 4px com cantos arredondados após cada seção, exceto a última (não adicione novos elementos à página, use ::after instead)
