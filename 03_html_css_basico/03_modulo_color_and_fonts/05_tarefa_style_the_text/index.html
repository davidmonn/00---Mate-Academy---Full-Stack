Aula Anterior - Relative Units

Tarefa: Style the Text

Intro

Nesta tarefa, vamos alterar a aparência da página usando o conhecimento adquirido.

Sua tarefa é:

  • 1) Conectar as fontes regular e negrito (bold) do Roboto, usando o Google Fonts.
  • 2) Definir Roboto como a fonte principal e Arial como fonte secundária da página (para a tag html); especificar a família de fontes correta.
  • 3) Definir o tamanho da fonte da página para 14px.
  • 4) O title deve ter um tamanho de fonte duas vezes maior que o da página (use unidades rem).
  • 5) Definir um fundo preto para title com uma opacidade de 0,8 no formato rgba.
  • 6) Definir um fundo cinza para o footer com um brilho de 25% do máximo para cada canal, usando o formato rgb.
  • 7) O tamanho da fonte no footer deve ser 20% maior do que no restante da página.
  • 8) Definir o tamanho da fonte para body como 18px; isso não deve afetar os elementos que foram estilizados acima.
