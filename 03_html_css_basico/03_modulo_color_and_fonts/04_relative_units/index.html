Diferentes Tamanhos

Podemos escolher o tamanho de diversas formas. Porem as mais utilizadas sao: px, em, vw/vh, % e rem.

rem

O rem é uma unidade relativa baseada no tamanho da fonte do elemento html (root). Ele é muito usado por ser mais previsível do que o em, já que não sofre influência de elementos pai. Com isso, conseguimos manter um controle mais consistente dos tamanhos no layout. Um exemplo comum é definir um tamanho padrão no html, como 16px, e todos os valores em rem serão calculados com base nesse valor.

em

O em é uma unidade relativa baseada no tamanho da fonte do elemento pai. Isso significa que seu valor pode variar dependendo do contexto onde está sendo usado. Por isso, ele pode ser menos previsível, já que sofre influência de outros elementos. Um exemplo comum é quando definimos um tamanho no body, e os elementos dentro dele utilizam em com base nesse valor.
