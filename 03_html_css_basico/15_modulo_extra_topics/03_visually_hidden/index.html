Explicacao

Com o exemplo que temos, agora iremos criar uma estrutura onde poderemos esconder o Link-2. Existem varias formas de fazermos essa ocultacao.

display: none;

Usando o display: none;, nesse caso apareceriam apenas o Link-1 e o Link-3. Dessa forma o Link-3 ficaria logo abaixo do Link-1, como se o Link-2 nao existisse.

visibility: hidden;

Dessa forma o elemento ficara oculto, mas ainda teremos o espaco reservado do Link-2.

opacity: 0;

Dessa forma o Link-2 ficara totalmente transparente, o que tambem mantera seu espaco reservado.

pointer-events: none;

Dessa forma, mesmo passando o mouse sobre um link, nao sera possivel interagir com ele. O elemento ira parecer apenas um texto comum.

Atributo hidden

Nesse caso podemos usar qualquer tag e adicionar o atributo hidden. Com ele, nosso elemento tambem ficara oculto.

Dica

Se quisermos que o elemento nao apareca nem mesmo na navegacao por teclado, como quando o usuario utiliza a tecla Tab, o mais indicado e usar o display: none;.
