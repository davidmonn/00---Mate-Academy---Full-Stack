Alteracao

Se mudarmos nosso CSS .title para .title:first-child e deixar ele por ultimo, ele acabara removendo o efeito de nosso hover, por ter o mesmo peso. Por isso e importante quando estivermos utilizando o :hover que ele fique no final para nao haver esses tipos de problemas.

id vs class:hover

Outro cuidado que tambem devemos ter pois nesse caso, se por exemplo desejarmos mudar a cor do background e o id tiver um, nosso hover com background acabara nao mudando, por conta do peso do id.
