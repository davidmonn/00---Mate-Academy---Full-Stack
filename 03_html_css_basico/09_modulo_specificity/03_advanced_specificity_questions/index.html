Nesse caso, como resultado o quem venceu foi a tag com pseudo-classe, como resultado obtendo o background-color: red;. Ambas tem o mesmo peso, porem como a com pseudo-classe veio depois, ela sobrepos a de cima.

Pseudo classe com tag

Se ambas tiverem a mesma tag e como resultado tiver pseudo-classe de mesmo peso, assim como ja dito, o resultado sera a que vier depois. Um exemplo disso baseado em nosso codigo de exemplo seri: 

                
                    
    body h1 {
        background-color: aliceblue;
    }

    body > :not(p) {
        background-color: antiquewhite;
    }
