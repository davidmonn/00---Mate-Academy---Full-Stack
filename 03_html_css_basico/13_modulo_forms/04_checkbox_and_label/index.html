Explicacao

Podemos observar que temos basicamente a mesma estrutura de nossa aula anterior. Porem agora temos o checkbox.

checkbox

Com ele sera criado um pequeno campo de marcacao, muito utilizado em casos onde usuarios precisam aceitar termos ou confirmar alguma opcao.

checkbox com value="yes"

Com isso, ao o usuario clicar em enviar, nosso banco de dados ao receber esse checkbox tera o valor de "yes".

Melhorias

Quando estamos trabalhando com formularios e checkbox, normalmente precisamos clicar especificamente no pequeno quadrado para marca-lo.

Isso pode acabar sendo um pouco ruim para alguns usuarios. Podemos utilizar o label para que mesmo clicando no texto de aceitar termos, por exemplo, o campo tambem seja marcado.

label

Podemos usar o label tanto por razoes semanticas quanto por motivos de usabilidade.

Com ele, alem de podermos clicar diretamente no campo, o proprio texto relacionado tambem pode ativar o campo desejado.

Temos duas formas principais de utilizarmos o label:

  • label usando id do input:
    • Dessa forma utilizamos o atributo for="" no label, passando o nome do id do input que sera vinculado.
  • label encapsulado:
    • Nessa forma basta encapsularmos o input dentro do proprio label, funcionando de maneira parecida com uma div.
