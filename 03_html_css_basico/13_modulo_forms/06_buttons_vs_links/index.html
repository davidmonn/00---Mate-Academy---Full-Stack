Buttons vs Links

Intro

Aqui iremos ver mais sobre botoes.

Codigo de Exemplo:

HTML:

button

Quando usamos a tag button, podemos fazer uso de alguns atributos como:

type="submit"

Com o type="submit", o button tera a funcao de enviar um formulario. Essa e a opcao que vem por padrao, entao se nao definirmos nenhum valor para o atributo type, ele sera definido automaticamente como submit.

type="reset"

Ele possui a funcao de limpar ou redefinir os valores de um formulario.

type="button"

Esse e diferente dos dois mencionados anteriormente, pois nao executa automaticamente uma acao relacionada ao formulario. Normalmente ele e utilizado para criarmos uma acao personalizada utilizando JS.

button

O button possui a vantagem de permitir o uso do atributo disabled, que serve para desabilitar o elemento. Isso pode ser util, por exemplo, quando um usuario ainda nao preencheu corretamente um formulario. Para controlar esse comportamento de forma mais eficiente, normalmente utilizamos JS.

Links

Diferente do button, os links sao utilizados principalmente para navegacao entre paginas, arquivos ou secoes de um site. Geralmente usamos a tag a junto do atributo href para definir o destino do link.
