Other Input Types

Intro

Aqui iremos ver outros tipos de inputs que podemos utilizar em nossos formularios.

Explicacao

O HTML possui diversos tipos de inputs, cada um sendo utilizado para diferentes necessidades em um formulario.

Para verificarmos todos os tipos disponiveis, podemos acessar a documentacao da Mozilla Developer Network (MDN).

Atraves da documentacao, conseguimos conhecer melhor os atributos, comportamentos e exemplos de utilizacao de cada tipo de input.

Exemplos de Input Types

Alguns exemplos muito utilizados sao:

  • text - Campo de texto simples
  • password - Campo para senhas
  • email - Campo para emails
  • number - Campo numerico
  • date - Campo de data
  • checkbox - Campo de multiplas escolhas
  • radio - Campo de escolha unica
  • file - Campo para envio de arquivos

Importante

Utilizar corretamente cada tipo de input ajuda na acessibilidade, melhora a experiencia do usuario e tambem permite que o navegador aplique validacoes automaticas em alguns campos.

Exemplo: ao utilizarmos um input type="email", o navegador pode verificar automaticamente se o valor informado possui um formato valido de email.
