Formularios

Formularios alem de serem usados para cadastros, tambem sao utilizados para pesquisas.

Como podemos observar em nosso codigo, temos apenas um form com input e button.

Ao clicarmos em nosso button de enviar, nada ira acontecer, pois nao passamos valores de parametros para nossa requisicao.

Para podermos observar o parametro de entrada, precisamos definir um name para nosso input. Exemplo:

Com isso, ficara da seguinte forma em nosso navegador como parametro de envio:

method

Temos dois valores de opcao para nosso parametro method, sendo eles: GET e POST.

GET

Com esse metodo, todos os valores da requisicao sao mostrados na url.

Esse nao e um formato muito adequado quando estamos trabalhando com senhas ou informacoes sensiveis, pois os dados ficarao visiveis no historico de navegacao.

POST

Com ele, nossas informacoes nao sao mostradas na url.

action

Dentro de action, passamos o valor de para onde serao enviados os dados das requisicoes feitas.
