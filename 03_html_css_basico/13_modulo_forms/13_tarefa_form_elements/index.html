Tarefa: Form Elements

Intro

Crie um formulário com base na captura de tela e descrição abaixo:

  • os dados do formulário devem ser enviados para https://mate-academy-form-lesson.herokuapp.com/create-application usando o método POST;
  • deve haver 4 conjuntos de campos com títulos corretos e as classes fieldset;
  • o botão de enviar deve ter um tipo explícito;
  • todos os campos devem ter nomes e etiquetas;
  • use a classe row para adicionar algum espaço entre os campos;

O bloco Personal information, contendo:

  • surname e name são campos de texto;
  • age e um número entre 1 e 100 (18 por padrão);
  • birthday é uma data;
  • A caixa de seleção accepted é obrigatória e deve ter um valor yes;

O bloco Registration, contendo:

  • Campo email obrigatório com placeholder;
  • Campo password obrigatório, contendo de 6 a 30 caracteres;

O bloco An interesting fact about you!, contendo:

  • Botões de seleção (radio button) cats com valores yes ou no;
  • Entradas de color e time;
  • Seleção múltipla de cars com as opções bmw, audi e skoda;
  • Escala rate de 0 a 5 com passo 1 e valor 0;

O bloco Additional info:, contendo:

  • Área de texto comments sem conteúdo;
  • Seleção recommend com valores yes e no.
