Explicacao

Podemos observar que temos basicamente o mesmo codigo da aula anterior, porem com algumas mudancas como name e informacao de cada campo. Alem disso podemos usar mais alguns atributos para facilitar a identificacao de nossos campos.

Atributo: placeholder

Usado para passar um valor em nosso campo de atributo, assim que o usuario digar, o valor dentro do campo ira sumir, usado apenas para deixar mais intuitivo para o usuario.

Atributo: value

Funciona de maneira parecida com o placeholder porem esse valor passado nao e apagado, podendo ate ser enviado para nosso servidor ao enviar o formulario.

Atributo: readonly

Tambem funciona de forma parecida ao value, porem o valor passado nao pode ser alterado.

Atributo: disabled

Com ele a informacao tambem nao pode ser alterada em nosso campo porem seu valor nao e enviado junto do formulario, isso pois esta desabilitado (desabled)
