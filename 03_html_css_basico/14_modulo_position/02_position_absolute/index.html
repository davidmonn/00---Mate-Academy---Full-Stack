Explicacao

Aqui podemos observar que estamos usando basicamente o mesmo codigo da aula anterior.

position: absolute;

Ao alterarmos o valor do position de relative para absolute, podemos observar algumas mudanças.

O elemento passa a poder se sobrepor aos outros elementos da página e deixa de ocupar seu espaço original dentro do fluxo normal do documento.

Além disso, o elemento com position: absolute; pode não respeitar o posicionamento do elemento pai caso ele não possua um posicionamento definido, podendo acabar vazando ou quebrando o layout da página.
