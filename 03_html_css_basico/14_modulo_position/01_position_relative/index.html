Ao utilizarmos um position, teremos liberdade para usar propriedades como: top, right, bottom e left.

Propriedade position

Temos alguns valores importantes para a propriedade position, como: relative, absolute, fixed e static.

  • relative:
    • Permite mover o elemento utilizando top, right, bottom e left, mantendo o espaço original do elemento na página.
  • absolute:
    • Remove o elemento do fluxo normal da página e permite posicioná-lo livremente.
  • fixed:
    • Mantém o elemento fixo na tela, mesmo quando a página é rolada.
  • static:
    • É o valor padrão dos elementos HTML, sem posicionamento especial.

Position Relative

O valor relative permite mover um elemento em relação à sua posição original.

Nesse caso, o elemento será movido 10px para baixo a partir de sua posição original utilizando top: 10px;.

Mesmo sendo movido, o elemento continuará ocupando seu espaço original dentro do fluxo da página.

Propriedade z-index

Com a propriedade z-index podemos definir qual elemento ficará acima ou abaixo de outro.

Quanto maior o valor do z-index, maior será a prioridade do elemento na sobreposição.

Propriedade opacity

A propriedade opacity permite definir a transparência de um elemento.

O valor vai de 0 até 1, onde:

  • 0 = totalmente transparente.
  • 1 = totalmente visível.
