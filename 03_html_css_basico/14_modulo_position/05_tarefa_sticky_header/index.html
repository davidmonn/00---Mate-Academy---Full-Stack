Aula Anterior - Sticky Header

Tarefa: Sticky Header

Intro

Resolva a tarefa abaixo:

  • O bloco nav deve ter uma posição sticky (aquela que permanece fixa no topo da página durante a rolagem)
  • Adicione um elemento < div > ao body com a classe scrollTop, dentro da qual haverá um link com a classe scrollTop__link para o topo da página
  • Crie as variáveis --button-height e button-width e use-as para especificar a largura e a altura da classe scrollTop
  • Use o caractere ↑ na cor branca e tamanho de fonte de 30px para o texto do link
  • A classe scrollTop deve ser posicionada em relação à tela do navegador (deslocamento a partir da borda direita - 32px, a partir de baixo - 64px)
