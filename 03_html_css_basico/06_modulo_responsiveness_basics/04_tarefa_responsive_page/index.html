Tarefa: Responsive Page

Intro

Crie uma página com blocos header, main e footer com classes correspondentes, onde:

  1. Para o bloco .header:
    • Defina a altura como 40px.
    • Defina o plano de fundo como preto (use a cor #000).
    • Adicione o texto “Header Content” em branco (#fff), centralizado horizontal e verticalmente.
  2. Para o .main:
    • Adicione quatro seções, onde:
    • Cada tag de seção tem a classe section.
    • Cada seção contém pelo menos 30 palavras e tem um padding de 20 px.
    • A segunda e a quarta seções devem ter um plano de fundo (use as classes section-2 e section-4 e qualquer cor, exceto branco).
    • A largura do texto nas seções deve estar entre 500px e 960px (adicione um div wrapper que tenha a classe container).
    • O plano de fundo se estende até a largura total da tela.
    • O texto dentro das seções deve ser exibido no centro do bloco horizontalmente.
  3. Para o .footer:'
    • Defina a altura do rodapé como 60px.
    • Defina o plano de fundo como cinza escuro (use a cor #444).
    • Adicione o texto “Footer Content” (Conteúdo do rodapé) em branco (#fff), centralizado horizontal e verticalmente.
    • Certifique-se de que o rodapé permaneça na parte inferior da janela quando não houver conteúdo suficiente para preencher a página:
      • Se houver muito conteúdo, ele deverá permanecer dentro de seu contêiner, sem transbordar.
      • Habilite a rolagem vertical quando necessário.
      • Impedir a rolagem horizontal quando a largura da janela for >= 540px.

Considere que os parâmetros do bloco podem mudar, portanto, planeje seu layout para acomodar ajustes sem erros.

Use as variáveis CSS --header-height, --footer-height para definir as propriedades css relevantes.
