Viewport Width and Height

Intro

Aqui iremos ver como definir as dimensões de um elemento com base na viewport (tela do usuário).

Exemplo

Neste exemplo, iremos configurar o body e um elemento inner.

body com margin: 0; e background-color: yellow;.

inner com height: 300px; e background-color: blue;.

Alterações

Se tentarmos alterar o inner para height: 100%;, perceberemos que ele pode "sumir", mesmo aplicando o mesmo ao body. Isso acontece porque o body não é o elemento raiz da página.

Se adicionarmos no CSS: html { height: 100%; }, então o inner passará a ocupar 100% da altura da página.

Hierarquia

Mesmo com isso funcionando, se o elemento estiver em um nível mais profundo da hierarquia, será necessário definir explicitamente a altura de todos os elementos pais.

Para evitar isso, podemos utilizar vh (viewport height), que representa a altura da tela, e vw (viewport width), que representa a largura da tela.

Dessa forma, mesmo sem definir a altura de html e body, o elemento continuará funcionando corretamente, pois depende apenas do tamanho da tela.

Esse é um ótimo recurso para responsividade, pois os elementos se adaptam automaticamente ao tamanho da viewport.
