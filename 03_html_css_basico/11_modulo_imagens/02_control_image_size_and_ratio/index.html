Control Image Size and Ratio

Intro

Aqui iremos aprender como controlar o tamanho e a proporcao das imagens utilizando propriedades do CSS.

Explicacao

Podemos observar que estamos trabalhando com uma imagem grande. Para conseguirmos ajustar a proporcao dessa imagem e fazer com que ela se adapte corretamente a diferentes tamanhos de tela, podemos utilizar algumas propriedades do CSS.

Uma das principais propriedades utilizadas para isso e a width, que permite controlar a largura da imagem.

.photo

Podemos adicionar uma class para nossa imagem, como .photo, para facilitar futuras modificacoes e organizacao do codigo.

Por exemplo, ao utilizarmos:

width: 100%;

A imagem tentara ocupar toda a largura disponivel do elemento pai.

height

Tambem podemos utilizar a propriedade height para definir uma altura especifica. Porem, dependendo do valor utilizado, a imagem pode acabar ficando achatada ou distorcida.

Resolvendo Imagem Achatada - object-fit: contain;

Essa propriedade faz com que a imagem mantenha sua proporcao original, encaixando completamente dentro do espaco disponivel.

Em alguns casos a imagem pode acabar ficando pequena em relacao ao espaco disponivel. Para isso podemos utilizar:

object-fit: cover;

Com ele, a imagem ocupa melhor o espaco disponivel, porem algumas partes podem acabar sendo cortadas.


Para controlar melhor a area visivel da imagem, podemos utilizar:

object-position

Exemplo: object-position: center -50px;

Onde:

  • center centraliza a imagem
  • -50px ajusta o foco da imagem verticalmente

Modificacoes no main

Tambem podemos utilizar imagens diretamente no background do elemento.


Exemplo:

background-image: url("imagem.png");

Em alguns casos podemos esconder a imagem original utilizando:

display: none;

Assim ficamos apenas com a imagem aplicada no background.

Algumas imagens podem acabar se repetindo automaticamente. Para impedir isso utilizamos:

background-repeat: no-repeat;

Para controlar o tamanho da imagem de fundo:

background-size: cover;

E para posicionar a imagem corretamente:

background-position: center;
