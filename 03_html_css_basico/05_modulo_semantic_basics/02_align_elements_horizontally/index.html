Aula Anterior - Semantic Page Structure

Align Elements Horizontally

Intro

Aqui iremos entender melhor sobre o alinhamento de elementos em uma página.

Explicação

Nesta aula, iremos aprimorar um cabeçalho, adicionando uma imagem e alinhando todos os seus itens, aprendendo na prática sobre alinhamento e centralização.

Atalho usado

header.header>nav.nav>a.nav_link*4 — com esse atalho, criamos rapidamente um cabeçalho com suas respectivas classes.

display: flex;

Nesta aula utilizamos o display: flex; para organizar melhor os elementos da página. Com o flex, temos um controle maior e mais simples sobre o alinhamento dos elementos.

align-items: center;

Utilizado para alinhar os itens verticalmente. Com ele, conseguimos centralizar os elementos dentro do container.

justify-content: center;

Usado para alinhar os elementos horizontalmente, centralizando-os dentro do container.
