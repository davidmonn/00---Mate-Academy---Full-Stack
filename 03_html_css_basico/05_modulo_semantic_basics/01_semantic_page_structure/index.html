Semantic Page Structure

Intro

Agora iremos aprender sobre a estrutura padrão de uma página HTML e como organizar melhor seus elementos.

Geral

Normalmente, páginas web possuem uma estrutura bem definida, como um nav (navegação) para acessar diferentes partes do site, uma área de conteúdo principal com as informações mais importantes e, ao final, um rodapé (footer) com dados gerais sobre a empresa ou o site.

Exemplo

No link abaixo você poderá visualizar um exemplo prático do conteúdo apresentado nesta aula.

Informações Adicionais

Dentro do corpo da página, podemos utilizar diferentes níveis de títulos, como h1, h2 e h3, organizando o conteúdo de acordo com a seção em que cada parte está inserida.

Resumindo:

Nosso projeto ficou estruturado com nav para navegação, main para agrupar o conteúdo principal e melhorar a organização, section para dividir o conteúdo por seções, article para separar temas específicos e, por fim, um footer com as informações finais do site.
