Tarefa: Navigation Semantic

Intro

Na tarefa final, vamos adicionar um pouco de semântica ao nosso código para melhorar a acessibilidade de nossa página para robôs e assistentes de voz.

Tarefa:

  1. Divida esse código em 3 blocos semânticos: header, main e footer
  2. Todas as tag div devem ser substituídas por tags semânticas (como no exemplo do vídeo)
  3. O header contém uma tag nav com uma lista de links
  4. O bloco main contém o heading de primeiro nível e section a classe container
  5. section contém o heading de segundo nível e article
  6. article contém um título de terceiro nível e dois parágrafos de texto
  7. footer contém apenas texto
