Tarefa: Navigation List

Intro

Desenvolva a tarefa abaixo:

  1. Coloque .logo e .nav em uma única linha usando display: flex para .header.
  2. Centralize verticalmente o conteúdo de .header usando align-items: center.
  3. Faça o espaçamento entre .logo e .nav até as bordas usando justify-content: space-between.
  4. Defina um padding horizontal de 20px dentro de .header e remova o padding vertical.
  5. Adicione uma lista ul com a classe nav__list dentro da navegação.
  6. Envolva cada nav__link em um li com a classe nav__item e o inclua na lista.
  7. Organize os links em uma única linha com uma distância de 20px entre eles.
  8. Desabilite os marcadores na lista usando a propriedade list-style: none.
  9. Remova o espaçamento desnecessário na lista (tanto interno quanto externo).
  10. Transforme os links em blocos, e garanta que a área clicável seja 10px mais larga que o texto (5 de cada lado) e 20px mais alta e mais baixa (ou seja: com 10 na parte de cima e na debaixo).
  11. Defina um fundo cinza de #666 para os links para mostrar que o texto está localizado no centro da área clicável.
