Aula Anterior - Combine CSS Selectors

Tarefa: CSS Selectors

Intro

Uma marcação com classes pré-definidas é fornecida. Estilize a página de acordo com as regras definidas sem alterar a marcação.

  1. Defina box-sizing: border-box para todos os elementos na página
  2. Redefina os estilos do título < h1 > adicionados pelo navegador (margin, font-weight e font-size: medium)
  3. Redefina as margens dos parágrafos
  4. Adicione cursor: pointer para todos os elementos com atributo title
  5. Defina a cor darkmagenta para todos os links começando por https:
  6. Defina uma borda red sólida de 1px para todos os links que terminam com .html
  7. Adicione um sublinhado a todos os links dentro do bloco .nav (independentemente do nível de aninhamento)
  8. Defina o peso 700 para o texto nos parágrafos que são filhos diretos de main
  9. Defina a cor yellow para os links que têm a classe .active
  10. Adicione uma borda sólida black de 5px para o elemento que está após o título < h1 >
