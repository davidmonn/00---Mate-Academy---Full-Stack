Seletores

Sao uma maneira de encontrar elementos em uma pagina, um exemplo seria quando usamos h1 {} quando fazemos isso, estamos selecionando de uma forma global todos os h1 da pagina. Alem de usar as proprias tags podemos tambem fazer uso de class usando ponto e nome da class, id usamos #nome do id, tambem temos o seletor universal usamos apenas o * {}.

Seletor de atributo

Quando desejamos fazer um seletor por atributo, usamos colchetes com o nome do atributo, por exemplo: [teste]. Com isso, selecionamos todos os elementos que possuem o atributo teste.

Também é possível selecionar atributos específicos, como id ou class, por exemplo: [id] ou [class]. Além disso, podemos verificar valores, como em [class="teste"] ou até partes do valor com [class*="teste"].
