Tarefa: Style It Up

Intro

Altere style.css e index.html para que a página funcione conforme descrito abaixo:

  • A página consiste de header, footer e 9 blocos entre eles
  • A largura de todos os blocos é de 300 pixels
  • A altura de todos os blocos é de 100 pixels
  • Os blocos contêm as seguintes cores:
    • header - blue
    • footer - black
    • important - red
    • interesting - green
    • surprising - orange
  • Não há recuos verticais entre os blocos
  • Todos os blocos estão dispostos horizontalmente no meio da página.
  • Os atributos id são substituídos pelos atributos class
  • A classe block é adicionada para estilização dos blocos
