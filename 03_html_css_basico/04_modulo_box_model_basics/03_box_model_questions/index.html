Entendendo Tamanho

Quando criamos um elemento qualquer valor aplicado nele e somado, como por exemplo no elemento Box criado, ele possui 300px porem se adicionarmos um border: 5px solid black; e um padding: 10px; agora ele nao tera mais um height: 300; mas sim com a soma das mudancas passaria a ter no total 330px

Explicacao

Com isso por mais que as vezes queremos criar um elemento com um tamanho fixo temos que tomar cuidado ao acrescentar mais propriedades.

box-sizing: content-box;

Por padrao o elemento que criamos tem um box-sizing: content-box;, se tivermos o objetivo de utilizar uma caixa que mantenha o tamanho original do tamanho que definimos, podemos mudar o box-sizing para border-sizing: border-box;
