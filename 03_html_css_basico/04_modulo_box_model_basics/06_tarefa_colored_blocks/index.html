Tarefa: Colored Blocks

Intro

Adicione à página 3 blocos < div > coloridos para que estejam posicionados um abaixo do outro.

Requisitos:

  • Todos os blocos devem ter a classe block, que define a altura como 100px.
  • O primeiro bloco deve ter a classe red, que torna o fundo vermelho.
  • O segundo bloco deve ter a classe green, que torna o fundo verde.
  • O terceiro bloco deve ter a classe blue, que torna o fundo azul.
  • As margens externas margin no elemento < body > são zeradas.
  • Todos os estilos estão localizados em style.css.
