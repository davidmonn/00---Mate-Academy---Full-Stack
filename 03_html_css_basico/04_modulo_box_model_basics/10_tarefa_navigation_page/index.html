Tarefa: Navigation Page

Intro

Vamos programar a primeira página com navegação.

Tarefa:

  • Navegacao:
    • Crie uma
      com a classe nav
    • Adicione 4 links dentro da nav com a classe link como Home, About, Courses e Contacts. Eles devem levar às páginas html correspondentes Defina o fundo preto para nav
    • Alinhe o link no centro do bloco nav
    • Faça um link branco sem sublinhado
    • Remova os recuos em torno da navegação (margin: 0 para body)
    • Defina 10px para recuos verticais dentro de nav
    • Defina 20px para recuos horizontais dentro dos links
    • Use a fonte Arial, Helvetica, sans-serif com tamanho de fonte de 16px para toda a página (html)
  • Conteudo:
    • Adicione < h1 > à página com o texto Mate academy
    • O texto do título deve estar centralizado
    • Adicione um texto à página (o texto está no final da tarefa)
    • Divida o texto em dois parágrafos. O segundo parágrafo começa após a 4ª frase
    • Limite a largura dos parágrafos para 500px
    • Use text-align: justify para distribuir o texto de forma homogênea ao longo do parágrafo
    • Posicione os parágrafos no centro da página (margin: 0 auto)
    • Crie uma
      com uma classe container e inclua os parágrafos nela
    • Mova os estilos de largura e alinhamento dos parágrafos para o bloco container
  • Rodape
    • Crie uma
      com uma classe footer
    • Adicione o texto © Copyright 2021, Mate academy dentro de footer
    • Defina dimgray como cor do plano de fundo e a cor de texto branca para footer
    • Inclua o texto no meio do bloco
    • Defina a altura do bloco para 100px

Dica:

  • Para colocar o texto verticalmente no meio, basta definir line-height igual à sua altura no container.
  • O link para a página Home deve ser index.html.
