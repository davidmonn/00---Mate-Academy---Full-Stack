Tarefa: Image - URL

Intro

Os links podem incluir mais do que apenas texto. Vamos adicionar um link com uma imagem dentro.

Você pode usar a imagem abaixo ou outra de sua preferência.

Pepe: `https://i.imgur.com/bCBt6ga.jpg`

Requisitos:

  • A tag contém o atributo href preenchido corretamente
  • A tag < a > contém a tag < img >
  • A tag < img > contém o atributo src preenchido corretamente com o endereço da imagem
  • A tag < a > contém o atributo target com o valor _blank
