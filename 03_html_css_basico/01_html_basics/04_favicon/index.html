Tarefa: Favicon

Intro

Complete o layout básico da página adicionando o ícone do site. Adicione a tag < link > dentro da tag < head >.

Requisitos para o favicon:

  • A tag < link > esteja dentro da tag < head >
  • A tag < link > possua um atributo rel com valor correto
  • O atributo href esteja definido como icon.png no nosso caso.
