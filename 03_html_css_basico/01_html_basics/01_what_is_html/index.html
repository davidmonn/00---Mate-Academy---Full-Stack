Whats is HTML

Intro

Aqui iremos focar em conhecer melhor o HTML e sua estrutura de criacao.

Titulos

Podemos representar titulos no HTML por meio de < h1 > e indo ate h6.

Paragrafos

Para criacao de paragrafos usamos o < p >.

Listas

Para listas temos duas opcoes < ol > order list (lista ordenada) e < ul > lista nao ordenada.

links

Para links podemos usar o < a >.

Imagens

Usamos < img >.

Icone

Podemos tambem adicionar icones em nosso site, para isso em nosso head iremos criar um a (link) e dentro de sua propriedade rel="icon" adicionamoso icon e na propriedade de href adicionamos o caminho ate a imagem.
