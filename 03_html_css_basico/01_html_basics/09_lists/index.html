Tarefa: Lists

Intro

Nesta tarefa, vamos adicionar 2 listas ao nosso HTML. A primeira lista será ordenada - < ol >. Crie uma lista ordenada de 3 elementos onde os mesmos sejam os nomes dos maiores continentes do planeta:

  • 1. Eurasia
  • 2. Africa
  • 3. North America

A segunda lista será não ordenada < ul > e irá conter 5 itens. Por exemplo, frutas. Fica a seu critério como desejar nomeá-los.

Requisitos para a tarefa:

  • < ol > seja usado
  • < ul > seja usado
  • < ol > contém 3 elementos com os nomes dos continentes. A ordem é importante
  • < ul > contém pelo menos 5 elementos. O conteúdo dos elementos não é importante
