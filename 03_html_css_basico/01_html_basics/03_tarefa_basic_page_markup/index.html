Tarefa: Basic Page Markup

Intro

Crie uma página HTML básica com o texto Hello world.

Passos para implementação:

  • Adicione no topo
  • Adicione a tag < html > com o atributo lang="en"
  • Adicione as tags < head > e < body > ao < html >
  • Adicione o termo Hello world como conteúdo na tag < body >
  • Adicione a tag < title > ao Hello world na tag < head >
  • Adicione a tag < meta > à tag < head > (não inclua a tag de fechamento)
  • Adicione o atributo charset com o valor UTF-8 à tag < meta >
