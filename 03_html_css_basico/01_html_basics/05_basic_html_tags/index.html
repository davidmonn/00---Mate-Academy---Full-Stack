Basic HTML Tags

Intro

Aqui iremos ver como podemos estar adicionando conteudos em nossa pagina.

head e body

Dentro de nosso head apenas tera conteudos que basicamente nao tera ou nao sera visto pelo usuario como algumas configuracoes ou titulo de nossa pagina, icone e etc.

Ja dentro de nosso body tera os nossos conteudos para os usuarios.

Atalho

As vezes teremos muitas coisas para podermos digitar por exemplo se tivermos uma lista de ul > li podemos simplificar seu uso para nao ter que digitar diversas vezes com um atalha como: ul>li>{Aqui pode ficar o conteudo} ou tb ul>li>{item-$}. Dessa forma com o {item-$} o sifrao ($) ira nos ajudar a fazer por exemplo uma contagem automatica se a lista tiver dois itens ficaria baicamente: item 1, item 2, item 3.
