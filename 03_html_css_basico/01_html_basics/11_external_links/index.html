Tarefa: External Links

Intro

Complete a marcação HTML adicionando alguns links para outras páginas.

Exemplos:

  • https://www.mate.academy
  • https://www.google.com
  • https://www.facebook.com

Requisitos para a tarefa:

  • Todas as tags < a > devem conter o atributo href com links para os recursos
  • Todas as tags < a > devem conter o atributo href com links para os recursos
  • Ao menos uma tag < a > precisa conter o atributo target com o valor _blank
  • As tags < a > devem conter o texto dentro para descrever o link.
