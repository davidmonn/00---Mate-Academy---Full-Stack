Tarefa: Inline Styles

Intro

Adicione estilos inline, para que o texto dentro das tags < em >, < strong > e < a > pareça um texto regular.

Requisitos de marcação:

  • coloque o estilo font-style: normal dentro da tag < em >.
  • use o estilo font-weight: normal para a tag < strong >.
  • coloque os estilos color: black; text-decoration: none; cursor: default dentro da tag < a >.
