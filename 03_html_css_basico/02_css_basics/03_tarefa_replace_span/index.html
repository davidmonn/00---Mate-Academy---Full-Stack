Tarefa: Replace Span

Intro

Muito provavelmente, você já sabe que os elementos podem ser estilizados de várias maneiras.

Substitua < em >, < strong > e < a > com tags < span > contendo atributos style, para que o texto se pareça como estava antes.

Dica: para substituir , e , você terá de usar as seguintes propriedades CSS: 

                
                    font-style:italic;
                    font-weight:bold;
                    cursor:pointer;
                    color:blue;
                    text-decoration:underline;
