Tarefa: Unique Classes

Intro

Elimine o id na marcação HTML. Substitua todos os atributos id por classes únicas. Use os mesmos nomes.

Requisitos para a tarefa:

  • As tags não tenham o atributo id.
  • Todos os atributos id sejam substituídos pelas classes correspondentes.
  • Seletores por id em style.css sejam substituídos por seletores de classe.
