Tarefa: Uppercased Paragraph

Intro

Para ver a herança de estilo em ação, adicione a classe aggregated ao terceiro parágrafo < p > com as tags aninhadas < em > e < strong > e converta o texto nele para maiúsculas.

Requisitos:

  • Estilos inline não devem ser usados;
  • A tag style não é usada;
  • O parágrafo com tags aninhadas < em > e < strong > contenha a classe aggregated;
  • Todas as letras dentro deste parágrafo estão em maiúsculas.
