Intro

Explicação

Em nosso código de exemplo, podemos observar que cada elemento possui seu próprio tamanho. Porém, se começarmos a diminuir o tamanho do elemento pai, perceberemos que o último elemento (box-3) ficará cada vez menor, até desaparecer completamente.

Se continuarmos diminuindo o tamanho do container, por padrão, quando não há espaço suficiente disponível, os elementos flexíveis começam a encolher proporcionalmente ao seu tamanho base. No caso do box-3, ele desaparece porque não possui conteúdo interno ocupando espaço.

Porém, também podemos alterar a proporção com que cada elemento diminui. Por exemplo, se quisermos que o segundo elemento encolha mais rapidamente que o primeiro, podemos definir um valor maior para a propriedade flex-shrink, como:

flex-shrink: 2;

Dessa forma, o segundo elemento perderá espaço mais rapidamente. Porém, o cálculo da redução é mais complexo, pois o tamanho base de cada item ainda é levado em consideração.

Caso utilizemos flex-shrink: 0;, o elemento não poderá ser reduzido.
