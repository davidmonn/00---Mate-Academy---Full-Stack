Explicacao

O comportamento dos elementos depende da direcao do eixo principal do container flexivel.

Propriedade gap: 20px;

Com ele iremos conseguir controlar o espacamento entre cada elemento.

Propriedade justify-content: center;

Com ele podemos estar centralizando nosso(s) elemento(s) de acordo com o tamanho disponivel do elemento pai. Nele temos outros valores como:

  • center
    • Usado para centralizar os elementos.
  • flex-end
    • Usado para colocar os elementos a direita.
  • flex-start
    • Usado para colocar os elementos a esquerda.
  • space-around
    • Centraliza e separa os elementos de acordo com o espaco.
