Intro

Agora iremos ver em uma das melhores oportunidades que o SASS nos proporciona. Como resultado ainda iremos manter a mesma estrutura das aulas anteriores "game".

cyclo

Se desejarmos adicionar mais linhas onde ira de 3 por 5

Para adicionarmos mais linhas, iriamos precisar adicionar mais 6 celulas em nosso HTML. Por mais que nosso campo aumentasse, nao teriamos modificadores para mover o elemento para quarta ou quinta linha. Poderiamos duplicar tambem os modificadores e editar, porem isso nos daria muito trabalho caso tenhamos muitas linhas de codigo.

Para isso podemos usar um cyclo.

Como usar cyclo

Em nosso SCSS podemos usar o sinal @ ficara da seguinte forma: 

                
                    @for $row from 1 through 3 {
                        &--y--#{row} {
                            top: ($row - 1) * $cell-size + $shift;
                        }
                    }

Interpretacao do Codigo:

  • @for
    • Usado para iniciar nosso cyclo
  • $row
    • aqui sera o nome de nossa variavel no caso $row
  • from
    • Aqui sera de onde iremos comecar.
  • 1
    • Em nosso caso escolhemos 1 para inciar.
  • through
    • Ate onde sera iterado
  • 3
    • Escolhemos iterar ate o valor 3
  • {} dentro dos colchetes
    • Adicionamos as resgras

Informacoes dentro dos colchetes:

Em nosso codigo podemos lembrar que anteriormente tinhamos em nosso SCSS &--y--1 porem alteramos com uso de cyclo para &--y--#{row} e o motivo por tras disso e simples, da forma anterior, estamos fazendo com uma unidade e altaramos para uma variavel. Porem para poder usar a variavel usamos o #{aqui dentro a variavel}.
