Aula Anterior - Mix block with parent element

Avoid code duplication with BEM block

Intro

Aqui iremos redesenhar o topo de nosso menu e do header para que sejam blocos idependentes, para que possamos reutilizar em dois lugares.

Dica Importante

Se algum codigo se repete ou deve sempre ser o mesmo. Ele deve ser escrito uma vez e reutilizado, podemos fazer isso simplesmente o levando para uma class separada e usando essa class duas vezes.
