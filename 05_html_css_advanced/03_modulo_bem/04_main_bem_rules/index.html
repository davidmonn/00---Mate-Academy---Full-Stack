O que é metodologia?

Metodologia é um conjunto de regras e padrões usados para organizar melhor o código.

BEM é a abreviação de 3 palavras: Block (Bloco), Element (Elemento) e Modifier (Modificador).

Essa metodologia ajuda a criar layouts mais organizados, reutilizáveis e fáceis de manter.

  • 1)
    • A interface é dividida em partes independentes, chamadas de blocos. Esses blocos podem ser reutilizados em outras páginas ou movidos para outros lugares da página sem alterar seu comportamento.
    • Um bloco pode possuir elementos. Os elementos dependem do bloco e normalmente recebem nomes relacionados a ele.
    • Também podemos usar modificadores, que servem para alterar aparência ou comportamento de um bloco ou elemento.
  • 2)
    • No BEM, evitamos aumentar a especificidade dos seletores sem necessidade. Isso deixa o CSS mais limpo, organizado e fácil de reutilizar.

O BEM proíbe aumentar a especificidade do seletor, a menos que seja realmente necessário.
