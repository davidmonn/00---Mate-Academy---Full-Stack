Podemos observar que existem muitas repetições em nosso código, sendo alterada apenas a quantidade de colunas em grid-template-columns. Para evitar isso, iremos criar uma variável. Ficará da seguinte forma:

Podemos observar que, utilizando apenas uma variável, conseguimos alterar somente a quantidade de colunas dentro dos @media, ficando da seguinte forma:

grid-template-columns: repeat(auto-fill, 100px);

Dessa forma, o Grid cria automaticamente o máximo possível de colunas de 100px. Mesmo que não existam elementos suficientes para ocupar todas elas, as colunas continuam existindo e o espaço permanece reservado.

grid-template-columns: repeat(auto-fit, 100px);

Funciona de forma parecida com o auto-fill, porém as colunas vazias são removidas. Assim, os elementos existentes podem ocupar melhor o espaço disponível.

grid-template-columns: repeat(auto-fit, minmax(100px, 200px));

Com ele conseguimos definir um tamanho mínimo e máximo para a largura dos cartões. Para isso, devemos remover o width: 100px; do elemento .card, evitando que ele tenha um tamanho fixo.

Nesse exemplo, cada cartão terá no mínimo 100px e poderá crescer até 200px, dependendo do espaço disponível.

Podendo ficar da seguinte forma:

grid-template-columns:

Com essa propriedade podemos configurar o tamanho e a quantidade de colunas do nosso grid. Alguns exemplos são:

  • grid-template-columns: repeat();
    • Permite repetir colunas sem precisar escrever os mesmos valores várias vezes. Exemplo: repeat(2, 100px) cria 2 colunas de 100px cada.
  • grid-template-columns: repeat(auto-fill, 100px);
    • Cria automaticamente o maior número possível de colunas de 100px, mesmo que algumas delas fiquem vazias.
  • grid-template-columns: repeat(auto-fit, 100px);
    • Também cria colunas automaticamente, porém remove as colunas vazias e distribui melhor os elementos existentes.
  • grid-template-columns: repeat(auto-fit, minmax(100px, 200px));
    • Permite definir um tamanho mínimo e máximo para as colunas, tornando o layout mais flexível e responsivo.
