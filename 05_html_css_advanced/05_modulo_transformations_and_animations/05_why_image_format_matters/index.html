Why image format matters

Intro

Aqui iremos continuar com nossas modificacoes do "Projeto BEM".

Iniciando

Para comecar iremos ver as adaptacoes de responsividade para o tablet, e feitas mais alteracoes como mixins. Tudo foi feito em nossa estrtura do "Projeto BEM".

Para iniciar comecamos mudando nosso logo e menu hamburguer, pois ao aproximar a imagem podemos reparar que perde a qualidade, para isso foi alterado para mesma imagem porem em .svg. Porem nao foi encontrado a imagem para fazer a alteracao.

Para o logo foi feito alteracao para um .png porem com 2x, pois assim manteria a qualidade e com um tamanho muito menor.

Fazemos isso pois hoje em dia, os telefones tem uma resolucao muito maior que um computador, portanto se adicionarmos uma imagem mais clara, ela tambem sera suavizada nos telefones. Por isso quando adicionamos uma imagem, devemos nao apenas prestar atencao na qualidade mas tambem ao tamanho da imagem, pois as imagens tem um maior impacto na velocidade de carregamento da pagina.
