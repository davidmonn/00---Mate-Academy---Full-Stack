Podemos observar que estamos fazendo uso o GoodList, que criamos anteriormente.

Organizando Lista

Queremos que ao precionarmos em alguma opcao dos botoes criados, seja feito uma organizacao. Nada ira funcionar no momento pois nao adicionamos nenhuma logica.

Para corrigirmos isso podemos inicialmente comecar em nosso button adicionar um manipulador de click, ira ficar da seguinte forma: 

import './App.scss';
import goodsFromServer from './goods.json';
import { GoodList } from './components/GoodList/GoodList';

export const App = () => {
  
  const sortById = () => {
    goodsFromServer.sort((good1, good2) => good1.id - good2.id)
  };
  

  return (
    < div className="App">

      < header>
        < button>Reset< /button>

        < div>
          Sort by:
          < button 
            onCLick={sortById}
          >
            id
          < /button>
          < button>name< /button>
          < button>color< /button>
        < /div>
      < /header>

      < GoodList goods={goodsFromServer} />

    < /div>
  )
};

Feito isso, mesmo apos clicarmos, ainda nao teremos resultado, isso ocorre pois o React, nao sabe que algo mudou, nao o informamos, e nao temos nenhum estado para chamar a funcao set. Entao precisamos armazenar nossa matrix no estado.

Para isso iremos criar uma nova variavel, iremos chama-la de [visibleGoods, setVisibleGoods] = useState('goodsFromServer(valor inicial)').

Feito isso passamos nossas novas variaveis sobre o estado de mudanca dentro de nosso codigo ficando da seguinte forma: 

import './App.scss';
import goodsFromServer from './goods.json';
import { GoodList } from './components/GoodList/GoodList';

import { useState } from 'react';


export const App = () => {
  
  const [visibleGoods, setVisibleGoods = useState(goodsFromServer);
  

  const sortById = () => {
    
    setVisibleGoods(
      visibleGoods.sort((good1, good2) => good1.id - good2.id)
    )
  
  };

  return (
    < div className="App">

      < header>
        < button>Reset< /button>

        < div>
          Sort by:
          < button 
            onCLick={sortById}
          >
            id
          < /button>
          < button>name< /button>
          < button>color< /button>
        < /div>
      < /header>

      < GoodList goods={visibleGoods} />

    < /div>
  )
};

Feito isso ainda nao estara completo, pois quando fazemos um retorno com referencia a mesma matrix o react acaba nao mudando o estado pois passamos a mesma referencia, para evitarmos esse problema podemos fazer uma copia e desestruturing, ficando da seguinte forma: 

import './App.scss';
import goodsFromServer from './goods.json';
import { GoodList } from './components/GoodList/GoodList';
import { useState } from 'react';

export const App = () => {
  const [visibleGoods, setVisibleGoods = useState(goodsFromServer);

  const sortById = () => {
    setVisibleGoods(
      [...visibleGoods].sort((good1, good2) => good1.id - good2.id)
    )
  };

  return (
    < div className="App">

      < header>
        < button>Reset< /button>

        < div>
          Sort by:
          < button 
            onClick={sortById}
          >
            id
          < /button>
          < button>name< /button>
          < button>color< /button>
        < /div>
      < /header>

      < GoodList goods={visibleGoods} />

    < /div>
  )
};

Resumindo, para o React saber sobre as mudancas, em vez de mutar o objeto existente (visibleGoods), temos que criar uma copia e passar outra matrix que sera renderizada, por isso fizemos [...visibleGoods]

Destacando Botao Apos Selecionado

Agora iremos ver por exemplo como podemos destacar o botao quando a ordenacao é feita pela id.

Para isso temos uma classe especial chamada Active, entao iremos adiciona-la agora ao nosso botao. 

import './App.scss';
import goodsFromServer from './goods.json';
import { GoodList } from './components/GoodList/GoodList';
import { useState } from 'react';

export const App = () => {
  const [visibleGoods, setVisibleGoods = useState(goodsFromServer);

  const sortById = () => {
    setVisibleGoods(
      [...visibleGoods].sort((good1, good2) => good1.id - good2.id)
    )
  };

  return (
    < div className="App">

      < header>
        < button>Reset< /button>

        < div>
          Sort by:
          < button onClick={sortById} className="active">id< /button>
          < button>name< /button>
          < button>color< /button>
        < /div>
      < /header>

      < GoodList goods={visibleGoods} />

    < /div>
  )
};

Mas temos um porem, queremos que so apareca essa modificacao apenas quando tudo estiver ordenado e seja clicada em sua determinada opcao.

Iremos comecar deixando nosso import { useState } no inicio, para que todas as bibliotecas venham primeiro nas importacoes.

Em seguidas iremos duplicas nossa import { useState } e mudaremos para import cn from 'classnames';.

Agora ao inves de usarmos constantemente a class active, a removemos e faremos da seguinte forma: 

import { useState } from 'react';
import cn from 'classnames';
import './App.scss';
import goodsFromServer from './goods.json';
import { GoodList } from './components/GoodList/GoodList';

export const App = () => {
  const [visibleGoods, setVisibleGoods = useState(goodsFromServer);

  const sortById = () => {
    setVisibleGoods(
      [...visibleGoods].sort((good1, good2) => good1.id - good2.id)
    )
  };

  return (
    < div className="App">

      < header>
        < button>Reset< /button>

        < div>
          Sort by:
          < button onClick={sortById} className={cn('active')}>id< /button>
          < button>name< /button>
          < button>color< /button>
        < /div>
      < /header>

      < GoodList goods={visibleGoods} />

    < /div>
  )
};

Feito isso para uma melhor legibilidade ja que queremos que nosso modificador apareca em determinada condicao, iremos primeiro organizar nosso codigo e criar uma nova variavel.

Essa nova variavel ira servir para que nos ajude a entender que a ordenacao esta acontecendo especificamente por id.

Essa nossa nova variavel iremos chama-la de const [sortField, setSortField] = useState('') por padrao a deixaremos vazia. Apos isso iremos em nosso button classNames e adicionamos a condicao que desejamos, ficando da seguinte forma: 

import { useState } from 'react';
import cn from 'classnames';
import './App.scss';
import goodsFromServer from './goods.json';
import { GoodList } from './components/GoodList/GoodList';

export const App = () => {
  const [visibleGoods, setVisibleGoods = useState(goodsFromServer);
  const [sortField, setSortField] = useState('');

  const sortById = () => {
    setVisibleGoods(
      [...visibleGoods].sort((good1, good2) => good1.id - good2.id)
    );
    setSortField('id')
  };

  return (
    < div className="App">

      < header>
        < button>Reset< /button>

        < div>
          Sort by:
          < button
            onClick={sortById}
            className={cn({ active: sortField === 'id' })}
          >
            id
          < /button>
          < button>name< /button>
          < button>color< /button>
        < /div>
      < /header>

      < GoodList goods={visibleGoods} />

    < /div>
  )
};

Porem aqui ainda temos um problema pois estamos usando um literario quando passamos em nosso className={cn({ ative: sortField === 'id' })}, seria facil acabarmos tendo um erro de digitacao dessa forma. Portanto em vez de usarmos um literal, precisamos criar uma constante e usa-la em dois lugares, podemos fazer isso acima de nosso componente. Iremos fazer da seguinte forma: 

import { useState } from 'react';
import cn from 'classnames';
import './App.scss';
import goodsFromServer from './goods.json';
import { GoodList } from './components/GoodList/GoodList';

const SORT_FIELD_ID = 'id';

export const App = () => {
  const [visibleGoods, setVisibleGoods = useState(goodsFromServer);
  const [sortField, setSortField] = useState('');

  const sortById = () => {
    setVisibleGoods(
      [...visibleGoods].sort((good1, good2) => good1.id - good2.id)
    );
    setSortField(SORT_FIELD_ID);
  };

  return (
    < div className="App">

      < header>
        < button>Reset< /button>

        < div>
          Sort by:
          < button
            onClick={sortById}
            className={cn({ active: sortField === SORT_FIELD_ID })}
          >
            id
          < /button>
          < button>name< /button>
          < button>color< /button>
        < /div>
      < /header>

      < GoodList goods={visibleGoods} />

    < /div>
  )
};

Implementando reset

Iremos comecar adicionando um onClick em nosso button reset.

Nele precisamos redefinir tanto o array quanto o sortField para seu estado inicial.

Para isso iremos criar uma funcao que realizara o reset, para isso iremos inicialmente criar uma nova const e chamaremos ela de reset, ela ira redefinir tudo para os valores padrao. Ira ficar da seguinte forma: 

import { useState } from 'react';
import cn from 'classnames';
import './App.scss';
import goodsFromServer from './goods.json';
import { GoodList } from './components/GoodList/GoodList';

const SORT_FIELD_ID = 'id';

export const App = () => {
  const [visibleGoods, setVisibleGoods = useState(goodsFromServer);
  const [sortField, setSortField] = useState('');

  const reset = () => {
    setVisibleGoods(goodsFromServer);
    setSortField('');
  } 

  const sortById = () => {
    setVisibleGoods(
      [...visibleGoods].sort((good1, good2) => good1.id - good2.id)
    );
    setSortField(SORT_FIELD_ID);
  };

  return (
    < div className="App">

      < header>
        < button>Reset< /button>

        < div>
          Sort by:
          < button
            onClick={sortById}
            className={cn({ active: sortField === SORT_FIELD_ID })}
          >
            id
          < /button>
          < button>name< /button>
          < button>color< /button>
        < /div>
      < /header>

      < GoodList goods={visibleGoods} />

    < /div>
  )
};
