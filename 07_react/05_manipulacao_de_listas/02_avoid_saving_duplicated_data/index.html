Aula Anterior: How to Sort a List

Avoid Saving Duplicated Data

Intro:

Anteriormente fizemos a implementacao de organizacao ao clicarmos em id assim como tambem o reset para voltar ao padrao. Porem nos deparamos com uma pequena duplicacao de dados. Atualmente temos os produtos iniciais(goodsFromServer) e o sortField, a partir dos quais podemos calcular a ordem atual. Porem o visibleGoods armazena as mesmas informacoes. Se em algum momento alterarmos o sortField e esquecermos o visibleGoods, ou vice-versa.

Teremos uma dessincronizacao, e nao ficara claro onde os dados corretos estao armazenados. Entao para evitarmos isso, podemos calcular o visibleGoods a cada renderizacao, em ves de salva-los.

Entendendo Melhor:

Para fazermos isso, iremos continuar de onde paramos na aula anterior, em nosso projeto react-app.

Iremos começar criando uma const que não faz parte do estado, mas que simplesmente copia a primeira array. Ou seja, iremos definir que visibleGoods será uma cópia da array de produtos iniciais. Ficando da seguinte forma: 

import { useState } from 'react';
import cn from 'classnames';
import './App.scss';
import goodsFromServer from './goods.json';
import { GoodList } from './components/GoodList/GoodList';

const SORT_FIELD_ID = 'id';

export const App = () => {
  const [sortField, setSortField] = useState('');
  const visibleGoods = [...goodsFromServer];

  const reset = () => {
    setVisibleGoods(goodsFromServer);
    setSortField('');
  }

  const sortById = () => {
    setVisibleGoods(
      [...visibleGoods].sort((good1, good2) => good1.id - good2.id)
    );
    setSortField(SORT_FIELD_ID);
  };

  return (
    < div className="App">

      < header>
        < button onClick={reset} >Reset< /button>

        < div>
          Sort by:
          < button
            onClick={sortById}
            className={cn({ active: sortField === SORT_FIELD_ID } )} 
          >
            id
          < /button>
          < button>name< /button>
          < button>color< /button>
        < /div>
      < /header>

      < GoodList goods={visibleGoods} />

    < /div>
  )
};

Feito isso, não precisaremos mais chamar o setVisibleGoods nessa etapa. Portanto, podemos apagá-lo. Faremos mais algumas modificações, deixando o código da seguinte forma: 

import { useState } from 'react';
import cn from 'classnames';
import './App.scss';
import goodsFromServer from './goods.json';
import { GoodList } from './components/GoodList/GoodList';

const SORT_FIELD_ID = 'id';

export const App = () => {
  const [sortField, setSortField] = useState('');
  const visibleGoods = [...goodsFromServer];

  
  if (sortField) {
    visibleGoods.sort((good1, good2) => good1.id - good2.id);
  }
  
  
  const reset = () => {
    setVisibleGoods(goodsFromServer);
  }

  const sortById = () => {
    setSortField(SORT_FIELD_ID);
  };
  

  return (
    < div className="App">

      < header>
        < button onClick={reset} >Reset< /button>

        < div>
          Sort by:
          < button
            onClick={sortById}
            className={cn({ active: sortField === SORT_FIELD_ID } )} 
          >
            id
          < /button>
          < button>name< /button>
          < button>color< /button>
        < /div>
      < /header>

      < GoodList goods={visibleGoods} />

    < /div>
  )
};

Podemos observar que foram feitas diversas pequenas mudanças. Em nossa função reset, retiramos a chamada de setVisibleGoods. Fizemos o mesmo em nossa função sortById, retirando a chamada de setVisibleGoods e mantendo apenas a ordenação com .sort((good1, good2) => good1.id - good2.id), que agora será realizada em outro local.

Feito isso, nossa ordenação será realizada durante a execução do componente, antes de o React atualizar a interface com a nova renderização.

Para isso, criamos a condicional if (sortField). Se sortField tiver um valor (ou seja, não estiver vazio), realizaremos a ordenação.

Feito isso, podemos simplificar ainda mais o código, passando arrow functions diretamente para os eventos onClick dos botões Reset e id. Ficando da seguinte forma:

Com isso, apagamos também as funções sortById e reset, já que elas não são mais necessárias. Agora, passamos diretamente as arrow functions para os eventos onClick dos botões.

Filtrando Dados

Se quisermos adicionar uma filtragem aos nossos dados, podemos utilizar o método filter() e atribuir o resultado novamente à variável visibleGoods. Para isso, precisaremos utilizar let em vez de const, pois iremos reatribuir um novo valor à variável. Ficando da seguinte forma: 

import { useState } from 'react';
import cn from 'classnames';
import './App.scss';
import goodsFromServer from './goods.json';
import { GoodList } from './components/GoodList/GoodList';

const SORT_FIELD_ID = 'id';

export const App = () => {
  const [sortField, setSortField] = useState('');
  let visibleGoods = [...goodsFromServer];

  
  visibleGoods = visibleGoods.filter(good => good.name.includes('o'));
  

  if (sortField) {
    visibleGoods.sort((good1, good2) => good1.id - good2.id);
  }

  return (
    < div className="App">

      < header>
        < button onClick={() => setSortField('')} >Reset< /button>

        < div>
          Sort by:
          < button
            onClick={() => setSortField(SORT_FIELD_ID)}
            className={cn({ active: sortField === SORT_FIELD_ID } )} 
          >
            id
          < /button>
          < button>name< /button>
          < button>color< /button>
        < /div>
      < /header>

      < GoodList goods={visibleGoods} />

    < /div>
  )
};

Organizando o Código:

Para organizarmos melhor nosso código, podemos criar uma function que recebe alguns parâmetros que desejarmos. Primeiro, iremos passar a nossa array, ficando da seguinte forma: function getPreparedGoods(goods, { sortField, query }). Passamos goods porque representa a array de produtos, sortField porque será o campo utilizado para a ordenação e query porque será o valor utilizado na filtragem. 

function getPreparedGoods(goods, { sortField, query }) {
  // Criamos uma variável para copiar a array goods
  let preparedGoods = [...goods];

  // Aqui criamos nossa filtragem
  preparedGoods = preparedGoods.filter(good => good.name.includes(query));

  // Essa será nossa condicional para ordenar
  if (sortField) {
    preparedGoods.sort((good1, good2) => good1.id - good2.id);
  }

  // Por fim, retornamos o resultado
  return preparedGoods;
}

Tudo ficará da seguinte forma:

import cn from 'classnames';
import './App.scss';

import { GoodList } from './components/GoodList/GoodList';

const SORT_FIELD_ID = 'id';

Porém, nossa filtragem só faz sentido se houver algum valor em query. Então, iremos adicionar uma condição para verificar se query possui um valor. Para isso, mudaremos apenas essa parte do nosso código: 

function getPreparedGoods(goods, { sortField, query }) {
  let preparedGoods = [...goods];
  
  if (query) {
    preparedGoods = preparedGoods.filter(good => good.name.includes(query));
  }
  

  if (sortField) {
    preparedGoods.sort((good1, good2) => good1.id - good2.id);
  }

  return preparedGoods;
}

Após fazermos isso, query poderá ser omitido ou receber uma string vazia, pois a filtragem só será realizada se ele possuir um valor verdadeiro.

Da forma como nosso código está agora, a ordenação funciona apenas para um campo (id). Então, iremos modificar nossa condicional if (sortField). Uma das opções que temos é utilizar o switch, que ficará da seguinte forma: 

function getPreparedGoods(goods, { sortField, query }) {
  let preparedGoods = [...goods];

  if (query) {
    preparedGoods = preparedGoods.filter(good => good.name.includes(query));
  }
  
  if (sortField) {
    preparedGoods.sort((good1, good2) => {
      switch (sortField) {
        case SORT_FIELD_ID:
          return good1[sortField] - good2[sortField];

        case SORT_FIELD_NAME:
        case SORT_FIELD_COLOR:
          return good1[sortField].localeCompare(good2[sortField]);

        default:
          return 0;
      }
    });
  }
  
  return preparedGoods;
}

Adicionamos um corpo {} à nossa função de comparação dentro do .sort(). Assim, dependendo do campo de ordenação, precisaremos comparar os produtos de maneiras diferentes.

Por que usamos good1[sortField] e good2[sortField] em vez de good1.id e good2.id?

Usamos good1[sortField] e good2[sortField] porque queremos acessar a propriedade dinamicamente, de acordo com o valor de sortField.

Por exemplo, se sortField for 'id', será o mesmo que escrever good1.id. Se for 'name', será o mesmo que escrever good1.name.

Essa definição vem do valor que passamos para setSortField() nos botões.

  • Por exemplo:
    • setSortField(SORT_FIELD_ID) → sortField recebe 'id'.
    • setSortField(SORT_FIELD_NAME) → sortField recebe 'name'.
    • setSortField(SORT_FIELD_COLOR) → sortField recebe 'color'.

Esses valores são definidos pelas constantes no início do código. O switch identifica o valor de sortField e decide como fazer a ordenação.

Após fazermos todas as mudanças em nossa function, dentro do nosso componente, precisaremos apenas chamar a função e passar a array inicial, além dos parâmetros de ordenação, filtragem e outros que desejarmos. No nosso caso, essa parte ficará assim: 

const visibleGoods = getPreparedGoods(goodsFromServer, { sortField, query: '' });

Modificações nos Botões

export const App = () => {

  // Criamos essa variável para receber o resultado da nossa função com os argumentos desejados

  return (
    < div className="App">

      < header>
        < button onClick={() => setSortField('')} >Reset< /button>
