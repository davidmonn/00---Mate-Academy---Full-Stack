Aula Anterior: How to Sort a List

Avoid Saving Duplicated Data

Intro:

Anteriormente fizemos a implementacao de organizacao ao clicarmos em id assim como tambem o reset para voltar ao padrao. Porem nos deparamos com uma pequena duplicacao de dados. Atualmente temos os produtos iniciais(goodsFromServer) e o sortField, a partir dos quais podemos calcular a ordem atual. Porem o visibleGoods armazena as mesmas informacoes. Se em algum momento alterarmos o sortField e esquecermos o visibleGoods, ou vice-versa.

Teremos uma dessincronizacao, e nao ficara claro onde os dados corretos estao armazenados. Entao para evitarmos isso, podemos calcular o visibleGoods a cada renderizacao, em ves de salva-los.

Entendendo Melhor:

Para fazermos isso iremos continuar de onde paramos da aula anterior em nosso projeto react-app.

Iremos comecar criando uma const nao no estado, mas simplesmente copiar a primeira array. Ou seja, iremos escrever que visibleGoods sera uma copia da array de produtos iniciais. Ficando da seguinte forma: 

import { useState } from 'react';
import cn from 'classnames';
import './App.scss';
import goodsFromServer from './goods.json';
import { GoodList } from './components/GoodList/GoodList';

const SORT_FIELD_ID = 'id';

export const App = () => {
  const [sortField, setSortField] = useState('');
  const visibleGoods = [...goodsFromServer];

  const reset = () => {
    setVisibleGoods(goodsFromServer);
    setSortField('');
  }

  const sortById = () => {
    setVisibleGoods(
      [...visibleGoods].sort((good1, good2) => good1.id - good2.id)
    );
    setSortField(SORT_FIELD_ID);
  };

  return (
    < div className="App">

      < header>
        < button onClick={reset} >Reset< /button>

        < div>
          Sort by:
          < button
            onClick={sortById}
            className={cn({ active: sortField === SORT_FIELD_ID } )} 
          >
            id
          < /button>
          < button>name< /button>
          < button>color< /button>
        < /div>
      < /header>

      < GoodList goods={visibleGoods} />

    < /div>
  )
};

Podemos observar que foram feitas diversas mudancas pequenas. Em nossa funcao reset apagamos o setVisibleGoods. Mudamos tambem em nosso sortById tambem apagamos nosso setVisibleGoods recortamos apenas nosso .sort((good1, good2) => good1.id - good2.id)

Feito isso nossa ordenacao sera feita imediatamente antes da renderizacao.

Feito isso criamos nossa condicional if (sortField) se tivermos sortField(nao estiver vazio), realizamos a ordenacao.

Organizando Codigo:

Para organizarmos melhor nosso codigo podemos estar criando uma function onde ela recebe alguns parametros que desejarmos, primeiro iremos passar o parametro de nosso array ficando da seguinte forma: function getPreparedGoods(goods, { sortField, query }), passamos goods pois é a array. sortField pois sera nossa organizador e query nosso filtragem. 

function getPreparedGoods(goods, { sortField, query }) {
  //Criamos uma variavel para desestruturar nosso array goods
  let preparedGoods = [...goods];

  //Aqui criamos nossa filtragem
  preparedGoods = preparedGoods.filter(good => good.name.includes(query));

  //Essa sera nossa condicional para ordenar
  if (sortField) {
    preparedGoods.sort((good1, good2) => good1.id - good2.id);
  }

  //Por fim fazemos o retorno
  return preparedGoods;
}

Tudo ficara da seguinte forma:

Porem nossa filtragem so faz sentido se houver algum query, entao iremos adicionar uma condicao para nosso query, onde mudaremos apenas essa parte de nosso codigo: 

function getPreparedGoods(goods, { sortField, query }) {
  let preparedGoods = [...goods];
  
  if (query) {
    preparedGoods = preparedGoods.filter(good => good.name.includes(query));
  }
  

  if (sortField) {
    preparedGoods.sort((good1, good2) => good1.id - good2.id);
  }

  return preparedGoods;
}

Apos fazermos isso nosso query ja nao é mais obrigatorio.

Dessa forma que temos nosso codigo agora, nossa ordenacao funciona apenas para um campo(id), entao iremos fazer uma modificacao em nossa condicional if (sortField), uma opcao que temos e iremos fazer é o uso de switch nela, onde agora ira ficar da seguinte forma: 

function getPreparedGoods(goods, { sortField, query }) {
  let preparedGoods = [...goods];

  if (query) {
    preparedGoods = preparedGoods.filter(good => good.name.includes(query));
  }
  
  if (sortField) {
    preparedGoods.sort((good1, good2) => {
      switch (sortField) {
        case SORT_FIELD_ID:
          return good1[sortField] - good2[sortField];

        case  SORT_FIELD_NAME:
        case  SORT_FIELD_COLOR:
          return good1[sortField].localeCompare(good2[sortField]);
        

        default:
          return 0;
      }
    });
  
  return preparedGoods;
}

Adicionamos um corpo{} a essa funcao, onde dependendo do campo de ordenacao, precisaremos comparar produtos de maneiras diferentes

Poque usamos good1[sortField] e good2[sortField] ao inves de good1. e good2. ?

Apos fazermos todas as mudancas em nossa funciton, dentro de nosso componente, apenas iremos precisar chamar a funcao e passar a array inicial, e todos os parametros de orgenacao, filtragem e etc que desejamos no caso sendo essa parte: 

const visibleGoods = getPreparedGoods(goodsFromServer, { sortField, query: '' });
