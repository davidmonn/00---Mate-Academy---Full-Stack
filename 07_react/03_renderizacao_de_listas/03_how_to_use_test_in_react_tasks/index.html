How to Use Test in React Tasks

Intro:

Aqui iremos ver sobre testes de tarefas React, como usa-los e porque sao necessarios.

Entendendo Melhor:

Para isso iremos baixar o repositorio de MoviesList nessa tarefa, como em muitas outras que faremos, ja termeos um layout pronto no arquivo App.jsx e com classes preparadas. Porem para ver se esta tudo adequado, escrevemos testes, eles sao programas que verificam a correcao de nossa solucao.

Esses testes requerem vinculacoes especiais, a determinados elementos na pagina, eles sao executados usando atributos como data-cy="algum nome". Temos dois tipos de testes, componentes especificos seram testados primeiro, em tarefas desse tipo, ja temos uma pasta de components, existindo diretorios para cada component que precisarmos implementar.

Os testes para components individuais sao como pequenos programas onde podemos ver ele com final .spec.
