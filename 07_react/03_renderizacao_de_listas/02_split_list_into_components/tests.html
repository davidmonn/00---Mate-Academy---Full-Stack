Intro:

Anteriormente, usamos um array de dados para imprimir uma lista de produtos na página. Porém, no uso cotidiano, esse cartão pode ficar muito maior, com muitas tags, alguma lógica adicional e assim por diante. Então, geralmente faz sentido extraí-lo para um componente separado.

Entendendo Melhor:

Para entendermos melhor, continuaremos em nosso projeto react-app e continuaremos com o mesmo conteúdo (código) da aula anterior. Sendo as alterações no App.jsx e nossa criacao do goods.json.

Separando Componentes

Para iniciar iremos inicialmente já criando uma nova variavel em nosso App.jsx e nomeá-la igual a class, e ela será um componente que retorna JSX, ficando da seguinte forma: 

import './App.scss';
import goods from './goods.json';

const GoodCard = () => (
  < div
    key={good.id}
    className="GoodCard" style={{ color: good.color }}
  >
    {`${good.name} ${good.id}`}
  < /div>
);

export const App = () => (
  < div className="App">

    < h1>Goods List

    < div className="GoodList">

      {goods.map(good => (
        < GoodCard />        
      ))}

    < /div>

  < /div>
);

Feito isso, o componente ainda não está completo, pois o GoodCard não sabe o que é good. Precisamos passar esse dado por meio de props.

Iremos começar passando a propriedade good, que recebe o objeto do produto da iteração. Ficará da seguinte forma: 

import './App.scss';
import goods from './goods.json';

const GoodCard = ({ good }) => (
  < div
    key={good.id}
    className="GoodCard" style={{ color: good.color }}
  >
    {`${good.name} ${good.id}`}
  < /div>
);

export const App = () => (
  < div className="App">

    < h1>Goods List

    < div className="GoodList">

      {goods.map(good => (
        < GoodCard good={good} />        
      ))}

    < /div>

  < /div>
);

Feito isso agora ira funcionar. Porém ao verificarmos na devTools veremos um erro:

O problema é que separamos o atributo key da iteração real. E na verdade não é mais necessário em nosso elemento onde se encontra, ele será necessário na tag que fica dentro da iteração após o map. Então iremos remover o key de onde ele esta no momento e iremos passar ele para dentro de nossa tag com a iteração. Ficando da seguinte forma: 

import './App.scss';
import goods from './goods.json';

const GoodCard = ({ good }) => (

    className="GoodCard" style={{ color: good.color }}
  >
    {`${good.name} ${good.id}`}
  < /div>
);

export const App = () => (
  < div className="App">

    < h1>Goods List

    < div className="GoodList">

      {goods.map(good => (
        < GoodCard good={good} key={good.id}  />        
      ))}

    < /div>

  < /div>
);

Feito isso, o aviso deverá desaparecer. Já separamos o componente GoodCard; agora podemos fazer o mesmo com o GoodList.

Para isso também iremos fazer o mesmo, criar uma nova variavel com o mesmo nome que retornara JSX:

Após criarmos a função que retorna JSX, iremos recortar nossa tag GoodList e colá-la dentro dessa nova função.

Em seguida, podemos inserir o componente da mesma forma que fizemos com < GoodCard />. Ficará da seguinte forma: 

import './App.scss';

);

  < div className="GoodList">

Claro que cada componente deve estar em seu próprio arquivo. Além disso como cada um deles tem seus próprios estilos, pode haver alguns outros arquivos, dito isso iremos criar alguns diretorios/arquivos para cada um deles.

Separando Arquivos

Dentro de nosso src iremos criar dois diretórios sendo eles GoodList e GoodCard onde cada um deles tera dois arquivos com seus respectivos nomes um em JSX e outro em SCSS, ficando da seguinte forma:

Após isso começaremos com a separacao.

Iremos começar recortando nosso const GoodCard e colando-o no arquivo GoodCard.jsx. Faremos o mesmo com GoodList. Além disso, também precisamos usar export e import.

Em nosso GoodCard, iremos colocar o export antes de const e importar seu arquivo SCSS.

Em nosso GoodList será um pouco diferente, temos que passar parâmetros para ele por conta do goods, então agora ele recebera o parâmetro goods e será nossa array. Em seguida dentro de nosso GoodList, precisa aceita-lo.

Tudo ficara da seguinte forma: 

import './App.scss';

import { GoodList } from './components/GoodList/GoodList';
import goods from './goods.json';


export const App = () => (
  < div className="App">

    < h1>Goods List< /h1>

    < GoodList goods={goods} />

  < /div>
);

Alteracoes feitas, podemos observar que alem de recortarmos nosso código de GoodList e GoodCard, foi preciso mais algumas alterações. Como:

Opcoes

Opcionalmente, podemos não passar todos os elementos. Por exemplo, podemos passar apenas os 5 primeiros. Para isso, em nosso App.jsx, podemos usar o método slice no valor da prop goods da tag GoodList. Exemplo: 

import './App.scss';
import { GoodList } from './components/GoodList/GoodList';
import goods from './goods.json';

export const App = () => (
  < div className="App">

    < h1>Goods List< /h1>

    < GoodList goods={goods.slice(0, 5)} />

  < /div>
);

Em nosso GoodList.jsx, iteramos sobre a prop goods recebida e renderizamos um cartão (componente/card) para cada produto. É importante adicionar a prop key ao componente renderizado dentro do map. Essa key deve ser única entre os elementos irmãos e ajudar o React a identificar cada item.

O componente GoodCard já contem o layout necessário para cada cartão.

Uma coisa que podemos melhorar é a forma como importamos o arquivo. Em nosso App.jsx, precisamos repetir GoodList no caminho do import e no nome importado:

App.jsx

import { GoodList } from './components/GoodList/GoodList';

Isso pode ser evitado se criarmos um arquivo de índice, então em nosso diretório GoodList iremos criar um novo arquivo e chamá-lo de index.js, iremos querer exportar tudo desse arquivo, e para fazermos isso em nosso index.js ficara da seguinte forma: 

export * from './GoodList';

Usamos o asterisco *, para exportar tudo dentro de nosso './GoodList';. Agora para conectarmos esse arquivo index.js, iremos precisar especificar o caminho para o diretório e por padrao a importação procurará o arquivo index.

Com isso agora em nosso App.jsx podemos fazer da seguinte forma: 

import './App.scss';
import { GoodList } from './components/GoodList';
import goods from './goods.json';

export const App = () => (
  < div className="App">

    < h1>Goods List

    < GoodList goods={goods.slice(0, 5)} />

  < /div>
);

Com isso, usamos apenas o caminho do diretório no import, sem repetir o nome do arquivo GoodList.

Podemos fazer o mesmo com GoodCard.

Por que não escrever tudo diretamente no index.js ?

O problema é que nossos arquivos então terao todos o nome indexIndex e isso não seria conveniente, pois nem sempre entenderemos pelo nome qual componente é.
