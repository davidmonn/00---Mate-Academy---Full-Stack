Render List from an Array

Intro:

Agora iremos ver como gerar listas de elementos React a partir de um array de dados.

Iniciando:

Iremos iniciar abrindo nosso projeto react-app e criaremos um layout simples em nosso App.jsx e tambem um array, onde ela estara armazenada no arquivo goods.json, este é um formato de dados especial, semelheante a objetos e arrays JavaScript, mas com restricoes adicionais.

Exemplo: em JSON, todas as strings devem estar entre aspas duplas "". Aspas simples ou acentos nao sao permitidos. Alem de strings podemos usar numeros, valores true e false, e null, undefined nao é permitido. Objetos e arrays tambem sao permitidos, e qualquer outra coisa nao é permitido.

Escolhemos o formato JSON pois é um formato de compartilhamento de dados mais popular entre cliente e servidor.

Feito isso iremos querer ter nao apenas 3 cartoes de produtos em nossa pagina, mas um cartao para cada elemento na array. Para fazermos isso, precisamos importar a array de dados. Como criamos nosso goods.json ao lado de nosso App.jsx, podemos apenas importa-lo da seguinte forma:

Apos fazermos nossa importacao, iremos querer remover uma parte de nosso codigo, para podermos inseri-la de forma correta. Usar loops ou outros builds que nao sejam expressoes, ou seja, nao retornam valores, nao é permitido no jsx.

Em vez disso iremos usar um metodo que gerara um array de elementos JSX. Exemplo: para cada elemento em nossa array de goods.json, iremos querer retornar uma tag como a que montamos com GoodCards e no React isso é feito usando o metodo Map.

Inserindo Json

Iremos comecar retornando uma parte de nossa tag sendo ela: 

< div className="GoodCard">
    Potato
< /div>

Feito isso podemos apagar as outras tags deixando a GoodList onde dentro dela iremos inserir chves {}, ou seja, de JSX passamos para JavaScript. Em seguida iremos usar a array goods e chamamos o metodo map nela, ficando da seguinte forma: 

import './App.scss';
import goods from './goods.json';

export const App = () => (
  < div className="App">

    < h1>Goods List< /h1>

    < div className="GoodList">

      
      {goods.map(good => (
        < div className="GoodCard">
          Potato
        < /div>
      ))}
      

    < /div>

  < /div>
);

Dessa forma ainda nao estara concluido, com isso estaremos apenas imprimindo "Potato" na mesma quantidade de array que temos.

Mas temos um objeto good (map), onde temos propriedades id, name e color. Entao dentro de nossa tag de map, ao inves de imprimirmos potato apagaremos o potato e colocaremos chaves {} em seguida pelo objeto good. Ex: {good.name} ou se desejarmos passar mais de uma informacao podemos fazer `${good.id} ${good.name}`. Ficando da seguinte forma: 

import './App.scss';
import goods from './goods.json';

export const App = () => (
  < div className="App">

    < h1>Goods List< /h1>

    < div className="GoodList">
      {goods.map(good => (
        < div className="GoodCard">
          {`${good.id} ${good.name}`}
        < /div>
      ))}

    < /div>

  < /div>
);

Alterando Cores do Texto

Outra coisa que podemos estar fazendo é alterando a cor do texto, utilizando da prorpiedade color que demos. Ficando da seguinte forma: 

import './App.scss';
import goods from './goods.json';

export const App = () => (
  < div className="App">

    < h1>Goods List< /h1>

    < div className="GoodList">

      {goods.map(good => (
        
        < div
          className="GoodCard" style={{ color: good.color }}
        >
        
          {`${good.name} ${good.id}`}
        < /div>
      ))}

    < /div>

  < /div>
);

Assim dessa forma teremos os resultados de nossa callbacks de forma certa como os nomes, ids e estilizacao.

Porem ainda temos um pequeno problema, onde se abrirmos nosso devTools veremos um erro em nosso console. Onde cada child deve ter uma chave unica. Oque é e para e porque precisamos, veremos mais tarde quando vermos sobre otimizacao de componentes React. Por enquanto apenas iremos adicionar um valor unico a cada tag.

Adicionando Valores Unicos as Tags

Temos uma iteracao de array sendo ele nosso {good.map(good => ())}, nele temos nosso metodo map, com isso em nossa primeira tag dentro do metodo map, precisamos adicionar o atributo key.

Dentro desse atributo deve haver um valor unico é muito importante que esse valor esteja vinculado de alguma forma ao nosso array. Para fazermos isso iremos usar o atributo key acessaremos o produto e sua propriedade id, ficando da seguinte forma: 

import './App.scss';
import goods from './goods.json';

export const App = () => (
  < div className="App">

    < h1>Goods List< /h1>

    < div className="GoodList">

      {goods.map(good => (
        < div
          key={good.id}
          className="GoodCard" style={{ color: good.color }}
        >
          {`${good.name} ${good.id}`}
        < /div>
      ))}

    < /div>

  < /div>
);

Feito isso estara corrigido nosso problema. Com o atributo key, o React sabera qual dado da array esta associada a cada elemento da pagina. Como temos um layout e muitos elementos sao criados, é necessario entender como cada div na pagina vinculada a algum objeto com dados ou algo mais, entao a key é uma vinculacao e é importante para a otimizacao.
