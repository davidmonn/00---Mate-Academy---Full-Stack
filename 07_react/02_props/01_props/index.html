Props

Intro:

Agora iremos nos aprofundar mais nos componentes do React e do JSX.

Entendendo Melhor:

Para entendermos melhor, iremos criar um "aplicativo", onde teremos 3 produtos e um título. Iremos fazer isso em nosso projeto react-app.

Iniciando

Iremos começar acessando nosso arquivo App.jsx e criando o seguinte código: 

export const App = () => (
  <div className="App">
    <h1>My Shop</h1>

    <div className="Product">
      <h2 className="Product__title">
        Pepperoni Pizza
      </h2>

      <div className="Product__price">
        Price: 100
      </div>
    </div>

    <div className="Product">
      <h2 className="Product__title">
        Chocolate Cake
      </h2>

      <div className="Product__price">
        Price: 30
      </div>
    </div>

    <div className="Product">
      <h2 className="Product__title">
        Water
      </h2>

      <div className="Product__price">
        Price: 0
      </div>
    </div>
  </div>
);

Agora que fizemos isso, iremos mover nosso componente para um arquivo separado.

Iremos criar uma nova pasta em src/components chamada Product. Dentro dela, criaremos dois arquivos: Product.jsx e Product.scss.

Dentro do arquivo Product.jsx, iremos criar nosso componente da seguinte forma: 

export const Product = () => (
  <div className="Product">
    <h2 className="Product__title">
      Pepperoni Pizza
    </h2>

    <div className="Product__price">
      Price: 100
    </div>
  </div>
);

Para um melhor entendimento, iremos observar os arquivos App.jsx e Product.jsx lado a lado:

Feito isso, podemos observar que temos basicamente 3 estruturas iguais de produtos no App.jsx. Então, em vez de repetirmos todo esse código, podemos reutilizar o componente Product usando a tag <Product />, importando-o para o arquivo App.jsx e utilizando-o três vezes. 

import { Product } from './components/Product/Product';

export const App = () => (
  <div className="App">
    <h1>My Shop</h1>

    <Product />
    <Product />
    <Product />
  </div>
);

Após fazermos isso, estaremos exibindo o mesmo produto três vezes. Porém, queremos produtos diferentes. Ou seja, precisamos reutilizar a mesma estrutura com dados diferentes.

Para isso, utilizamos propriedades (props), que permitem passar dados para um componente. Ficará da seguinte forma: 

import { Product } from './components/Product/Product';

export const App = () => (
  <div className="App">
    <h1>My Shop</h1>

    <Product
      title="Pepperoni Pizza"
      price={100}
    />
    <Product
      title="Chocolate Cake"
      price={30}
    />
    <Product
      title="Water"
      price={0}
    />
  </div>
);

Feito isso, ainda precisamos modificar nosso componente no arquivo Product.jsx para que ele receba e utilize essas propriedades. Para isso, iremos receber um objeto como parâmetro e extrair dele as propriedades title e price, ficando da seguinte forma: 

export const Product = ({ title, price }) => (
  <div className="Product">
    <h2 className="Product__title">
      {title}
    </h2>

    <div className="Product__price">
      Price: {price}
    </div>
  </div>
);

Resumindo, quando queremos reutilizar um componente com dados diferentes, podemos passar propriedades (props) para ele. Nesse exemplo, passamos as propriedades title e price. Dentro do componente, usamos essas propriedades para exibir os valores recebidos.

Quando passamos valores para nosso componente Product dentro do arquivo App.jsx, esses valores podem ser de diferentes tipos. Por exemplo: 

// App.jsx

import { Product } from './components/Product/Product';

export const App = () => (
  <div className="App">
    <h1>My Shop</h1>

    <Product
      title="Pepperoni Pizza"
      price={100}
    />

    <Product
      title="Chocolate Cake"
      // Não é possível exibir um objeto diretamente no JSX
      price={{ x: 1 }}
    />

    <Product
      title="Water"
      // O array será exibido sem separadores automáticos
      price={[0, 1, 2, 3]}
    />
  </div>
);

Lembrando que, quando exibimos um array de valores primitivos, seus elementos são renderizados sem separadores automáticos. Já um objeto comum não pode ser exibido diretamente como conteúdo do JSX, pois isso gera um erro.

Porém, podemos acessar uma propriedade específica do objeto. Como o produto Chocolate Cake recebe um objeto em price, podemos acessar sua propriedade x da seguinte forma: 

// Product.jsx

export const Product = ({ title, price }) => (
  <div className="Product">
    <h2 className="Product__title">
      {title}
    </h2>

    <div className="Product__price">
      Price: {price.x}
    </div>
  </div>
);

Porém, os outros produtos recebem números e um array, e não possuem a propriedade x. Por isso, o resultado de price.x será undefined nesses casos. Para evitar esse problema, precisamos tratar cada tipo de dado adequadamente.

Resumindo:

Para passar valores de diferentes tipos como propriedades, usamos chaves { } quando precisamos de uma expressão JavaScript. Exemplo: price={0}.

Para passar uma string, podemos usar aspas duplas diretamente. Exemplo: title="Pepperoni Pizza". Também podemos usar chaves: title={'Pepperoni Pizza'}.

Para exibir valores no JSX, usamos chaves { }. Podemos exibir strings, números e outros valores compatíveis, além de arrays que contenham elementos renderizáveis. Porém, não podemos exibir diretamente um objeto comum ou uma função como conteúdo.

Também podemos passar valores padrão para nossas propriedades. Por exemplo, no arquivo Product.jsx: 

export const Product = ({
  title = 'Produto',
  price = 0,
}) => (
  <div className="Product">
    <h2 className="Product__title">
      {title}
    </h2>

    <div className="Product__price">
      Price: {price}
    </div>
  </div>
);

Nesse exemplo, se title ou price não forem informados ou receberem undefined, serão utilizados os valores padrão definidos no componente.
