Conditional Rendering

Intro:

Agora iremos ver como fazer marcacoes diferentes o JSX dependendo de condicoes.

Entendendo Melhor:

Iremos continuar em nossa pagina react-app continuando codigo da aula anterior em nossa pagina Product.jsx.

Inciando Alteracoes:

Ja em nosso arquivo Product.jsx, iremos imprimir um span adicional com uma estrela para itens gratuitos. Ficando da seguinte forma: 

export const Product = ({ title, price }) => (
  < div className="Product">
    < h2 className="Product__title">
      {title}
    < /h2>

     div className="Product__price">
      Price: {price} < span>*< /span>
    < /div>
  < /div>
);

Apos feito isso, ira aparecer em todos nossos price, porem queremos que seja adicionado apenas em certas condicoes, ficando da seguinte forma em nosso site do projeto:

Adicionando Espacamento:

Se tudo estiver escrito em uma linha, como fizemos, sera incoveniente formata-lo, no React, geralmente dividimos cada parte em uma linha separada. Onde como exemplo o texto ficara na primeira linhae passamos nosso span para a segunda, quando fazemos uma quebra de linha, nao ficara mas espaco, pois quebra de linha nao é interpretada, entao para mantermos espaco, uma das opcoes que temos é quebrar outra linha entre as duas, e adicionamos chaves {} e entre elas aspas com espaco {' '}, ficando da seguinte forma: 

export const Product = ({ title, price }) => (
  < div className="Product">
    < h2 className="Product__title">
      {title}
    < /h2>

     div className="Product__price">
      Price: {price}
      {' '}
      < span>*< /span>
    < /div>
  < /div>
);

Porem essa sintaxe nao é muito utilizada, ao inves disso é mais conveniente, usarmos a interpolacao de JavaScript regulas. Entao iremos fazer da seguinte forma: 

export const Product = ({ title, price }) => (
  < div className="Product">
    < h2 className="Product__title">
      {title}
    < /h2>

     div className="Product__price">
    {`Price: ${price} `}
      < span>*< /span>
    < /div>
  < /div>
);

Adicionando Condicoes

Com a mesma abordagem que usamos na interpolacao podemos realizar algum calculo usando chaves {} e com operador ternario. Ficara da seguinte forma: 

export const Product = ({ title, price }) => (
  < div className="Product">
    < h2 className="Product__title">
      {title}
    < /h2>

     div className="Product__price">
    
    {`Price: ${price} `}
    {price === 0 ? < span>*< /span> : ''}
    
    < /div>
  < /div>
);

Quando usamos um operador ternario, é sugerido formatar cada parte em uma linha, quando fazemos isso, nossa sintaxe tambem acaba mudando um pouco: 

export const Product = ({ title, price }) => (
  < div className="Product">
    < h2 className="Product__title">
      {title}
    < /h2>

     div className="Product__price">
    {`Price: ${price} `}
    {price === 0 ? (
      < span>*< /span>
      ) : (
        ''
      )}
    < /div>
  < /div>
);

Outra opcao que tambem temos quando nao precisamos de um segundo valor, sendo passado, podemos usar o &&, Ex: {price === 0 &&} 

export const Product = ({ title, price }) => (
  < div className="Product">
    < h2 className="Product__title">
      {title}
    < /h2>

     div className="Product__price">
    {`Price: ${price} `}
    
    {price === 0 && (
      < span>*< /span>
    )}
    
    < /div>
  < /div>
);

Imrpimindo Mais Tag

O React nao permite adicionar mais de uma tag por padrao na sintaxe JSX e isso tambem se aplica a nosso component. Ex: 

Forma Errada

import './Product.scss';

export const Product = ({ title, price }) => (
  < div className="Product">
    < h2 className="Product__title">
      {title}
    < /h2>

    < div className="Product__price">
      {`Price: ${price} `}
      {price === 0 && (
        
        < span>*< /span>
        < span>*< /span>
        
      )}
    < /div>
  < /div>
);

O JSX sempre deve retornar uma tag, se nao desejarmos que haja algum involucro, div ou qualquer outra tag, podemos usar uma tag especial sendo ela: react.fragment, para isso iremos importar da biblioteca React. Ficando da seguinte forma: 

import React from 'react'
import './Product.scss';

export const Product = ({ title, price }) => (
  < div className="Product">
    < h2 className="Product__title">
      {title}
    < /h2>

    < div className="Product__price">
      {`Price: ${price} `}
      {price === 0 && (
        
        < React.Fragment>
          < span>*< /span>
          < span>*< /span>
        < /React.Fragment>
        
      )}
    < /div>
  < /div>
);

Sempre que desejarmos usar o React.Fragment podemos usar no lugar apenas <>< />. Exemplo: 

import React from 'react'
import './Product.scss';

export const Product = ({ title, price }) => (
  < div className="Product">
    < h2 className="Product__title">
      {title}
    < /h2>

    < div className="Product__price">
      {`Price: ${price} `}
      {price === 0 && (
        <>
          < span>*< /span>
          < span>*< /span>
        < />
      )}
    < /div>
  < /div>
);
