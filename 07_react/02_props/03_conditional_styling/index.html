Aula Anterior: Conditional Rendering

Conditional Styling

Intro:

Agora iremos ver como adicionar estilos condicionalmente.

Iniciando:

Iremos começar abrindo nosso arquivo react-app -> src -> components e acessando nosso Products/Products.jsx.

Agora iremos ao nosso componente. Para produtos que são gratuitos, queremos adicionar o modificador Product--free. Ficará da seguinte forma: 

import React from 'react';
import './Product.scss';

export const Product = ({ title, price }) => (
  <div className="Product Product--free">
    <h2 className="Product__title">
      {title}
    </h2>

    <div className="Product__price">
      {`Price: ${price} `}

      {price === 0 && (
        <React.Fragment>
          <span>*</span>
          <span>*</span>
        </React.Fragment>
      )}
    </div>
  </div>
);

Agora iremos ao nosso Product.scss para adicionarmos esse modificador. Após fazermos isso, veremos que todos os produtos que utilizarem essa classe receberão a modificação. Porém, o que queremos é adicioná-la apenas a produtos específicos.

Para isso, iremos precisar fazer uma verificação. Se quisermos calcular o valor de um atributo no JSX, precisamos usar chaves {}. Então, iremos voltar ao nosso Product.jsx e, no lugar da className, iremos adicionar chaves {} e escrever a expressão dentro de backticks. Exemplo: className={`Product ${price === 0 ? 'Product--free' : ''}`}. Dentro delas, podemos realizar o cálculo usando uma expressão JavaScript com ${'expressão'}, neste caso, com um operador ternário. Ficará da seguinte forma: 

import React from 'react';
import './Product.scss';

export const Product = ({ title, price }) => (
  <div className={{`Product ${price === 0 ? 'Product--free' : ''}`}}>
    <h2 className="Product__title">
      {title}
    </h2>

    <div className="Product__price">
      {`Price: ${price} `}

      {price === 0 && (
        <React.Fragment>
          <span>*</span>
          <span>*</span>
        </React.Fragment>
      )}
    </div>
  </div>
);

Podemos observar que essa sintaxe pode ficar um pouco complexa. Seria mais conveniente se pudéssemos especificar quais classes queremos adicionar de acordo com cada condição. Para fazer isso, podemos instalar a biblioteca classnames.

Instalando a biblioteca classnames

Para instalarmos essa biblioteca, iremos selecionar nosso projeto pelo terminal usando o comando cd. Após confirmarmos que estamos no projeto correto, podemos fazer a instalação.

Iremos usar o comando npm i classnames e pressionar Enter.

Após a instalação, para usarmos a biblioteca, precisamos fazer um import. Podemos escolher o nome que desejamos usar no código. Ficará da seguinte forma: 

import React from 'react';
import cn from 'classnames';
import './Product.scss';

export const Product = ({ title, price }) => (
  <div className={`Product ${price === 0 ? 'Product--free' : ''}`}>
    <h2 className="Product__title">
      {title}
    </h2>

    <div className="Product__price">
      {`Price: ${price} `}

      {price === 0 && (
        <React.Fragment>
          <span>*</span>
          <span>*</span>
        </React.Fragment>
      )}
    </div>
  </div>
);

Após isso, se necessário, reiniciamos nosso servidor de desenvolvimento. Para isso, basta cancelarmos o npm start com Ctrl + C e iniciá-lo novamente com o comando utilizado pelo projeto.

Usando classnames

Após fazermos a instalação do classnames, podemos duplicar nossa linha que utiliza a classe condicional para compararmos as duas formas. Depois, podemos comentar a primeira linha para testar a segunda.

Agora, dentro do atributo, chamamos a função cn(). Em seguida, podemos passar uma ou várias strings com as classes que sempre estarão presentes. Também podemos passar um objeto com as classes condicionais. Exemplo: className={cn('Product', { 'Product--free': price === 0 })}. Nesse objeto, as chaves serão os nomes das classes e os valores determinarão se elas serão adicionadas ou não. Ficará da seguinte forma: 

// Antes

<div className={{`Product ${price === 0 ? 'Product--free' : 'Product--default'}`}}>
</div>

// Depois

<div className={cn('Product', { 'Product--free': price === 0 })}>
</div>

Para termos uma melhor legibilidade e podermos adicionar outras classes, podemos fazer da seguinte forma: 

<div className={cn('Product', {
  'Product--free': price === 0,
  'Product--default': price > 0,
  'Product--expensive': price >= 100
})}>
</div>

À esquerda temos o nome da classe e, à direita, a condição para que ela seja adicionada.

Além das classes, também podemos alterar estilos diretamente no elemento. Por exemplo, podemos mudar a cor do nosso title dependendo de o produto ser gratuito ou não. Para isso, podemos usar o atributo style, aplicando o estilo diretamente no elemento, o que chamamos de CSS inline. Ficará da seguinte forma: 

import React from 'react';

// Adiciona a biblioteca classnames
import cn from 'classnames';

import './Product.scss';

export const Product = ({ title, price }) => (
  <div className={cn('Product', {
    'Product--free': price === 0,
    'Product--default': price > 0
  })}>
    <h2
      className="Product__title"
      style={{
        color: price === 0 ? 'blue' : 'red',
        backgroundColor: price === 0 ? 'yellow' : '',
        padding: price === 0 ? '10px' : '',
        borderRadius: price === 0 ? '10px' : ''
      }}
    >
      {title}
    </h2>

    <div className="Product__price">
      {`Price: ${price} `}

      {price === 0 && (
        <>
          <span>*</span>
          <span>*</span>
        </>
      )}
    </div>
  </div>
);

Feito isso, tudo funcionará normalmente. Dessa forma, para adicionarmos classes condicionalmente, podemos usar a biblioteca classnames.

As classes que estarão sempre presentes (fixas) serão escritas diretamente como strings. Já as classes que serão adicionadas condicionalmente serão escritas como chaves de um objeto, com suas respectivas condições.

Para adicionarmos estilos inline, usamos o atributo style e nele usamos chaves duplas {{}}. As chaves externas fazem a transição do JSX para uma expressão JavaScript, enquanto as internas representam um objeto JavaScript.

Nesse objeto, a chave é o nome da propriedade CSS em camelCase, como backgroundColor, e o valor pode ser calculado ou escrito explicitamente.
