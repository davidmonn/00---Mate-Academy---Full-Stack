Update Component State

Introdução:

Agora iremos ver sobre o estado de um componente React.

Entendendo Melhor:

Para entendermos isso, iremos continuar em nosso projeto react-app, onde criaremos um layout simples, que ficará da seguinte forma: 

import './App.scss';

export const App = () => (
  < div className="App">

    < h1>Value is 0< /h1>

    < button>1
    < button>2
    < button>3

  < /div>
);

Feito isso, queremos que o valor mude após clicarmos em algum desses botões. Iremos começar lidando com o evento de clique (click).

Evento de clique:

Em React, usamos um atributo chamado onClick para tratar cliques. O nome começa com on e, em seguida, vem o evento com a primeira letra maiúscula. Seu valor deve ser uma referência para uma função; também podemos escrever uma função diretamente, como uma arrow function. Ficando da seguinte forma: 

import './App.scss';

export const App = () => (
  < div className="App">

    < h1>Value is 0< /h1>

    < button onClick={() => {}} > 1 < /button>
    < button>2
    < button>3

  < /div>
);

Agora podemos iniciar fazendo um teste, no qual podemos imprimir o valor 1 no console, da seguinte forma: 

import './App.scss';

export const App = () => (
  < div className="App">

    < h1>Value is 0< /h1>

    < button onClick={() => {
      console.log(1);
    }} > 1 < /button>
    < button>2
    < button>3

  < /div>
);

Para verificarmos, podemos abrir nosso DevTools (F12/Inspecionar). Após fazermos o teste, iremos deixar nosso código da seguinte forma: 

import './App.scss';

export const App = () => (
  < div className="App">

    < h1>Value is 0< /h1>

    < button onClick={() => console.log(1)} > 1 < /button>
    < button onClick={() => console.log(2)} > 2 < /button>
    < button onClick={() => console.log(3)} > 3 < /button>

  < /div>
);

Agora queremos mudar o valor 0 exibido em Value is 0. Para isso, podemos tentar usar uma variável e refazer algumas partes, ficando da seguinte forma: 

import './App.scss';

export const App = () => {
  let value = 0;

  return (
    < div className="App">
      < h1>Value is 0< /h1>
      < button onClick={() => {value = 1; console.log(1);} } > 1 < /button>
      < button onClick={() => {value = 2; console.log(2);} } > 2 < /button>
      < button onClick={() => {value = 3; console.log(3);} } > 3 < /button>
    < /div>
  )
}

Obs: nosso código ainda não terá o resultado que desejamos. Embora a atribuição seja válida em JavaScript, alterar uma variável comum não faz o React renderizar o componente novamente. Colocamos console.log(1) para testar o clique. A função também pode ser escrita de forma curta, como neste exemplo: 

< button onClick={() => value = 1 } > 1 < /button>

Ou seja, usamos chaves para escrever várias instruções dentro da função. Nesse caso, não há um retorno explícito.

Para entendermos isso, iremos precisar descobrir quem realmente chama essa função. Para isso, iremos abrir nosso arquivo index.jsx.

Em nosso index.jsx, teremos as seguintes informações: 

import { createRoot } from 'react-dom/client';
import { App } from './App';
import './index.scss';

const element = document.querySelector("#root")

createRoot(element).render(

  < App />
    
);

Em nosso index.jsx, podemos ver a tag < App />. Ao renderizá-la, o React chama a função do componente App, que retorna o layout a ser exibido.

Esse layout é exibido na página pela raiz criada com createRoot(). O React chama a função do componente na renderização inicial e pode chamá-la novamente quando o estado muda.

Portanto, para obter o layout inicial, o React executa a função do componente, declarada em export const App. Para atualizar a interface após uma interação, precisamos atualizar o estado usando os recursos do React.

Em nosso componente App, uma variável comum como let value = 0; não é suficiente para controlar o estado, pois sua alteração não faz o componente renderizar novamente. Em React, usamos um Hook chamado useState, importado da biblioteca React.

Essa função é chamada de Hook. O useState permite guardar um valor entre renderizações. Chamamos essa função passando o valor inicial, que neste caso será 0. O exemplo ficará assim: 

import { useState } from 'react';
import './App.scss';

export const App = () => {
  let value = useState(0);

  return (
    < div className="App">
      < h1>Value is 0< /h1>
      < button onClick={() => {value = 1; console.log(1);} } > 1 < /button>
      < button onClick={() => {value = 2; console.log(2);} } > 2 < /button>
      < button onClick={() => {value = 3; console.log(3);} } > 3 < /button>
    < /div>
  )
}

A função useState retorna um array com dois elementos. Por isso, usamos a desestruturação para obter o valor atual e a função que permite atualizá-lo. Ficará da seguinte forma: 

import { useState } from 'react';
import './App.scss';

export const App = () => {
  let [value, setValue] = useState(0);

  return (
    < div className="App">
      < h1>Value is 0< /h1>
      < button onClick={() => {value = 1; console.log(1);} } > 1 < /button>
      < button onClick={() => {value = 2; console.log(2);} } > 2 < /button>
      < button onClick={() => {value = 3; console.log(3);} } > 3 < /button>
    < /div>
  )
}

O primeiro elemento, value, contém o valor atual do estado. O segundo, setValue, é a função usada para definir um novo valor, que será refletido na próxima renderização. Esse nome é uma convenção: usamos set seguido do nome do estado.

Explicação de [value, setValue]

value será o valor atual do estado.

setValue será a função usada para definir um novo valor para a próxima renderização.

Agora, em vez de atribuir um valor diretamente com value = 1, iremos chamar a função setValue e passar 1 para ela. Assim, o React será informado da atualização do estado.

Agora funcionará normalmente, ficando da seguinte forma: 

import { useState } from 'react';
import './App.scss';

export const App = () => {
  const [value, setValue] = useState(0);

  return (
    < div className="App">
      < h1>Value is {value}< /h1>
      < button onClick={() => {setValue(1)} } > 1 < /button>
      < button onClick={() => {setValue(2)} } > 2 < /button>
      < button onClick={() => {setValue(3)} } > 3 < /button>
    < /div>
  )
}

Adicionando 2 useState

Também podemos adicionar dois estados usando useState, da seguinte forma: 

import './App.scss';
import { useState } from 'react';

export const App = () => {
  const [value, setValue] = useState(0);
  const [message, setMessage] = useState('');

  return (
    < div className="App">

      < h1>Value is {value}< /h1>
      < p>
        {message}
      < /p>

      < button 
        onClick={() => {
          setValue(1);
          
          setMessage(message + 1);
          console.log(value);
          
        }}
      >
        1
      < /button>

      < button 
        onClick={() => {
          setValue(2);
          
          setMessage(message + 2);
          console.log(value);
          
        }}
      >
        2
      < /button>
      
      < button 
        onClick={() => {
          setValue(3);
          
          setMessage(message + 3);
          console.log(value);
          
        }}
      >
        3
      < /button>

    < /div>
  )
};

Podemos observar que o message acumula os números dos botões clicados, formando um histórico simples das interações. Também usamos dois Hooks useState. Mesmo que um clique atualize os dois estados, o React normalmente agrupa essas atualizações e faz uma única nova renderização ao final do evento.

Como a marcação dos botões é praticamente a mesma, podemos substituir os três botões por uma iteração com map(). Ficando da seguinte forma: 

import './App.scss';
import { useState } from 'react';

export const App = () => {
  const [value, setValue] = useState(0);
  const [message, setMessage] = useState('');

  return (
    < div className="App">

      < h1>Value is {value}< /h1>
      < p>
        {message}
      < /p>
      
      {[1, 2, 3, 4, 5].map(x => (
          < button
          key={x}
          onClick={() => {
            setValue(x);
            setMessage(message + x);
            console.log(value);
          }}
          >
            {x}
          < /button>
      ))}
      
    < /div>
  )
};

Observações Finais:

useState: usamos para informar ao React que determinado valor faz parte do estado do componente e que, ao atualizá-lo usando sua função de atualização, o componente poderá ser renderizado novamente.

Ao importarmos useState do React, o correto é:

import { useState } from 'react', e não from './react'.
