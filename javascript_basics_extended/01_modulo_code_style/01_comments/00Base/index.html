Intro

Nessa aula veremos sobre comentarios no JS.

Existem diferentes tipo de se fazer um comentario no JS.

Normalmente quando temos um comentario acima de nosso codigo, ele tem como objetivo explicar o objetivo da proxima linha. Tambem temos comentario em bloco usado quando queremos comentar um trecho de codigo, no caso mais de uma linha.

Comentario em uma Linha //

Para fazer comentario em uma unica linha usamos o //.

Comentario em Bloco

Para fazer um comentario em bloco usamos o /* Aqui o comentario */.
