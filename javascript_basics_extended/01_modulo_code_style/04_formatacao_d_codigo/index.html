Formatacao de Codigo

Intro

Aqui veremos algumas formas de estar melhorando a leitura de nosso codigo.

Boas Maneiras no Codigo

;

; uma das boas maneiras e sempre que terminarmos uma expressao, terminar com ponto e virgula (;).

camelCase

Esse metodo e muito utilizado, pois quando desejamos criar uma variavel com algum nome espeficil como por exemplo nome e sobrenome, poderia ficar da seguinte forma com o camelCase: nomeSobrenome. Sempre a primeira palavra minuscula e a proxima maiuscula.
