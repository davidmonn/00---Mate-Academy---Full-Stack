How to revert the changes with Git

Intro

Aqui iremos ver como reverter um commit realizado.

git revert

Para estarmos revertendo de um commit para revertelo iremos precisar de seu codigo hash que podemos estar obtendo com o git log --oneline .

Apos copiarmos o codigo podemos sair com o q e realizar o comando git revert 684cbc6 apos darmos enter. Ira abrir umas opcoes podemos estar usando o cntl x para sair e se desejarmos salvar apertamos no y
