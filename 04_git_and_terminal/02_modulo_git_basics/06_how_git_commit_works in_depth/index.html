How git commit works in-depth

Intro

Agora iremos ver um pouco mais sobre os comandos commit e add.

Explicacao git add .

Quando enviamos um arquivo por commit ele nao e enviado por inteiro, mas por parte.

Se por exemplo fizermos uma alteracao e dermos um git add . e decidirmos mudar mais alguma coisa e depois dermos um git status.

Iremos observar que o git add . ja foi realizado para a primeira parte que escrevemos, mas temos uma mudanca em nosso codigo que foi a alteracao feita apos o git add .

Se fizermos um commit da forma que esta agora, sera enviado apenas a primeira parte que temos o git add . e as modificacoes feitas apos isso, nao seram enviadas junto.

Se quisermos enviar tudo junto, iremos precisar novamente dar outro git add . e podemos verificar com um git status onde veremos que agora sim todos os arquivos seram enviado se dermos o git commit -m "".
