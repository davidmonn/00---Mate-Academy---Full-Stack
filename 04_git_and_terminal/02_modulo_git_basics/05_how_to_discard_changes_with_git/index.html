How to Discard Changes with Git

Intro

Aqui iremos ver como recuperar um codigo revertido.

Inciando Recuperacao

git log --oneline

Com isso iremos ver que foi feito um revert, com isso podemos copiar seu codigo hash.

git reset --hard

Apos copiarmos o codigo hash, usamos o git reset --hard com o codigo hash que foi copiado.

Removendo Algo que nao Queremos Enviar de Forma Sutil

Para isso podemos iniciar com o git add . com isso podemos usar o git status e iremos vereficar os arquivos modificados.

Se por exemplo tivermos dois arquivos um que precise ser enviado e o outro ainda esta sendo trabalhado. Podemos fazer um git commit -m"nome" e acabarmos enviando ambos. Podemos estar dando um git log --oneline novamente para pegar seu hash e fazemos o comando git reset --soft 72210de.

Apos darmos enteder podemos dar novamente um git status e copiamos o nome do arquivo que nao queremos enviar com o codigo git restore --staged exemplo.html com um arquivo foi enviado e restauramos o exemplo.html nao sendo enviado.
