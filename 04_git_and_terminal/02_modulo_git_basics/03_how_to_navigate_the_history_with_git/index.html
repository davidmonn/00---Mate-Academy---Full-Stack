How to navigate the history with Git

Intro

Aqui iremos ver como navegar no historico de commits que enviamos.

git log

Primeira coisa que estaremos fazendo e utilizar o git log. Apos usarmos ele e darmos enter, podemos estar navegando por todos os commits realizados, podemos usar a seta cima e baixo para navegar e se precisarmos sair, basta digitarmos a letra q.

git log --oneline

Tem mesma funcao do git log mas de forma mais resumida.

git log --oneline --patch

Dessa forma conseguimos ver os detalhes de todas as alteracoes que foram realizadas em cada um dos commits.

Entrando em um Commit ja feito

Ao usarmos o git log --oneline, veremos que temos alguns codigos, se o copiarmos podemos estar o usando com o comando git checkout.

git chekout

Com ele podemos estar selecionando um arquivo ja comitado, para isso iremos precisar do codigo do commit, que podemos estar obtendo ao usar o git log --oneline

git --oneline --all

Dessa forma conseguimos ver todos os commits que foram realizados e em que ponto estamos acessando nosso codigo.

git checkout main

Com ele voltamos para nosso arquivo principal que estamos no momento.
