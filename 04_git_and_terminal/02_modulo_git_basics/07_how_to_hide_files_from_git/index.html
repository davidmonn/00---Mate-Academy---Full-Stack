How to hide files from Git

Intro

Agora iremos ver como ocultar um arquivo que nao pode ser enviado para o repositorio mas que precisa fazer parte do projeto.

Ocultacao de Arquivo

A primeira coisa que iremos fazer e criar o arquivo que desejamos ocultar como .env .

Depois digitamos uma senha para exemplo onde nao podemos deixar essa senha disponivel em nosso repositorio. Feito isso podemos criar um aquivo que se chama arquivo. gitignore dentro desse arquivo digitamos o nome do arquivo que nao queremos enviar. Como por exemplo o arq.env que criamos de exemplo.

Com isso todos os arquivos/pastas que colocarmos dentro do .gitignore serao ignorado em nosso commit

Dessa forma iremos deixar disponivel apenas em nosso computador local e nao sera enviado para o repositorio
