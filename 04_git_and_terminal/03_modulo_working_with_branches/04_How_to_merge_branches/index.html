Intro

Agora iremos aprender a juntar duas branch em uma so.

Passo a Passo

Identificar branch

Primeira coisa que deveremos fazer é nos certificar em qual branch estamos.

Para podermos verificar iremos comecar com o git status. Caso estejamos em uma branch que nao seja a main, iremos precisar usar o comando git checkout feature/update-help-page apos o checkout é o nome da branch que iremos acessar, no caso iremos voltar para a main com git checkout main para podermos fazer o merge.

Apos fazermos as alteracoes necessarias em nossa branch, precisamos acessar nosso main para podermos juntar todo o codigo atualizado em nossa branch feature para a nossa branch principal. Para isso iremos usar o git marge. Importante: se tivermos algo em nossa branch secundaria ainda nao atualizado (sem o git add .) nao conseguiremos voltar para a principal.
