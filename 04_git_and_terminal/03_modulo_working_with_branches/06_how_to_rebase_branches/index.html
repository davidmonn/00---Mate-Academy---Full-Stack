How to rebase branches

Intro

Aqui iremos aprender a como usar o comando rebase.

rebase

Precisamos usa-lo quando queremos trazer para o topo uma branch em que estamos trabalhando.

Exemplo:

Por exemplo se estivermos trabalhando em um branch especificar e demoremos muito tempo nela, outras pessoas estaram integrando seus codigos na branch main. Com isso para recebermos todas essas mudancas que estao sendo feitas na branch main.

Estaremos precisando fazer uma atualizacao de nosso codigo em nossa branch que estamos criando sem precisar fazer um merge.

Com isso conseguimos usar o rebase, para que a gente consiga receber essas atualizacoes da branch principal, mesmo sem termos nossa funcionalida pronta para ser comitada com merge.

Na Pratica

Para isso como sempre iremos verificar em qual branch estamos git branch

Inciando

Um exemplo seria criarmos uma nova branch como por exemplo git branch feature/update-headers com esse exemplo, atualizariamos todos nossos headers (h2) e trocariamos para ela com o git checkout feature/update-headers

Com isso poderemos comecar a fazer as mudancas em nossa pagina, feito isso podemos fazer o padrao para enviar. git add . / git commit -m"" / git push

'Simulacao git rebase

Agora iremos simular a utilizacao do git rebase

Feito isso veremos que nossa pagina ainda nao esta atualizada, no caso ira ate aparecer um risco no nome isso pois fomos nos mesmo que criamos. Para que nao precisemos mandar um codigo incompleto para nossa branch principal, podemos fazer apenas o rebase.

Com ele iremos conseguir receber todas as atualizacoes de nosso codigo, para isso basta usarmos o git rebase main.

Conflito rebase

As vezes tambem pode acabar houvendo conflitos em nosso rebase, para isso podemos fazer igual anteriormente visto, escolhendo manter ambos os codigos e verificando se esta tudo correto. Com ele iremos conseguir receber todas as atualizacoes de nosso codigo, para isso basta usarmos o git reabase main.
