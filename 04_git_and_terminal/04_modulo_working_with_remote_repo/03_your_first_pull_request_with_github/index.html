Aula Anterior - Your first remote repository

Your first pull request with GitHub

Intro

Aqui iremos ver como fazer alteracoes em nosso codigo do repositorio local para o repositorio remoto.

Relembrando Primeiros Passos

git branch

Assim que entrarmos em um novo repositorio e formos trabalhar nele. Iremos criar uma branch para nao trabalhar diretamente com o main.

git branch new/feature

Com isso iremos criar uma nova branh chamada new/feature.

git checkout new/feature

Iremos usar para entrar na nova branch new/feature.

git add .

Apos feito uma atualizacao importante/alteracao. Podemos estar enviando tudo com essa opcao.

git commit -m "message"

Com ele iremos tanto enviar quanto adicionar uma mensagem de nossa atualizacao.

git push

Com ele iremos enviar para nosso repositorio remoto as atualizacoes feitas.

Parametro --set-upstream origin new/feature

Se for nossa primeira vez enviando esse commit para nosso repositorio remoto iremos precisar usa-lo. Tambem podemos abreviar esse comando com git push -u origin new/feature . origin e nosso repositorio remoto e o new/feature é o nome de nossa branch criada.

Voltando ao main

Quando voltarmos para nosso main pode haver situacoes onde nosso arquivo ou codigo nao esta disponivel quando estamos trabalhando por outra branch. Para que ele fique disponivel em nosso repositorio local iremos precisar usar o comando git pull.

git pull

Com ele iremos conseguir receber todas atualizacoes feitas em nosso projeto.
