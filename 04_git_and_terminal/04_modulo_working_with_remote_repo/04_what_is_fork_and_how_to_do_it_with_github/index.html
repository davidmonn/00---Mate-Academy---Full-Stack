Aula Anterior - Your first pull request with GitHub

What is Fork and how to do it with GitHub

Intro

Aqui iremover ver repositorio publico para alteracao/sugestao sem modificar projeto original.

Primeiros Passos

git fork

Para fazermos isso iremos precisar do comando git fork, dentro do priprio GitHub.

Apos encontrarmos o repositorio publico, podemos fazer uma copia para fazermos um copia corretamente sem afetar o projeto original. Iremos clicar na opcao de fork

Apos isso iremos conseguir criar nosso primeiro fork apos verificar as informacoes desse fork podemos clicar em Create Fork

Apos feito isso agora podemos copiar a url e fazer o download desse clone atraves do fork.
