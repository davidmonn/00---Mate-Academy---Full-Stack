Lógica AND

Intro

Agora veremos um pouco sobre a condicional AND. Com ela, para que uma condição seja considerada true (verdadeira), todas as condições precisam ser atendidas.

Exemplo

Como exemplo, podemos usar a carteira de motorista. Para consegui-la, precisamos cumprir alguns requisitos, como ser maior de idade, ter dinheiro para pagar as aulas e passar na prova. Se todas essas condições forem atendidas, o resultado será true no AND.
