Substituindo Caracteres em Strings

Intro

Agora iremos ver como podemos substituir caracteres dentro de uma string.

Substituindo caracteres

Quando estamos trabalhando com URLs, não é permitido utilizar espaços no texto. Por isso, precisamos substituir esses espaços por outros caracteres, como o hífen (-).

Exemplo

Neste exemplo, utilizamos um laço for para percorrer uma string e transformá-la em um formato de URL. A ideia é substituir todos os espaços por hífens (-), criando assim uma string formatada corretamente.
