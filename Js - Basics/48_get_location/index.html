Exercicio - Get Location

Enunciado Exercicio:

Estamos atualizando nossos robôs! Agora eles podem converter comandos de movimento em sinais e se mover de acordo com eles:

  • 'forward' se traduz em y + 1.
  • 'back' para y - 1.
  • 'right' para x + 1.
  • 'left' para x - 1.

Mas seria ótimo se o robô pudesse rastrear sua localização sem GPS. Portanto, vamos criar a função getLocation que aceita dois parâmetros:

  • coordinates - uma matriz de coordenadas iniciais no formato [x, y].
  • commands - uma matriz com um histórico de comandos como [‘command1’, ‘command2’, ‘command3’, ...].

A função deve retornar uma matriz de coordenadas finais ([x, y]) após o movimento de acordo com os comandos.

Exemplos:

1) As coordenadas após o primeiro comando são: [1, 1] (1 passo à esquerda).

2) Após o segundo comando - [1, 0] (1 passo para trás).

3) Após o terceiro comando - [1, -1] (1 passo para trás).

4) O resultado é a matriz [1, -1].
