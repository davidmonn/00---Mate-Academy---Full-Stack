Aula Anterior - Array

Array Elements

Intro

Iremos continuar a entender sobre arrays. Agora iremos aprender a recuperar e adicionar um elemento dentro de um array.

Exemplo

Iremos continuar com o mesmo exemplo da aula passada sobre lista de paises ou cidades.

.length

Se quisermos estar verificando a quantidade de valores dentro de um array, podemos usar o length para poder estar recebendo essa informacao. Para isso basta fazermos da seguinte forma:
console.log(countries.length) nesse caso como resultado, receberemos o valor 4, ja que temos 4 itens em nossa lista array.

Selecionando

Podemos estar tambem utilizando o indice para podermos estar identificando um unico elemento de nossa lista. Exemplo:
console.log(countries[0]) como resultado teremos Japao.

Agora se tivermos uma lista muito grande podemos fazer uma selecao da seguinte forma:
console.log(countries[countries.length-1]) Como resultado teremos o ultimo item de nossa lista array.

Substituindo/Adicionando novo elemento no array

Para podermos estar substituindo um novo elemento em nossa lista array podemos fazer da seguinte forma: passamos o nome do array > [indice] > nome do novo elemento. Exemplo: countries[2] = 'Brasil'

Agora se quisermos sempre adicionar no final de nossa lista temos duas formas, podemos fazer da seguinte forma:
countries[countries.length] = Brasil essa forma e menos usada. countries.push('Brasil'); mais usada. Alem disso com push podemos adicionar mais de um elemento de uma vez so.
