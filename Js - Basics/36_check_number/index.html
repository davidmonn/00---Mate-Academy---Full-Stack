Check Number

Enunciado Exercicio

Vamos recapitular como trabalhar com números. Escreva a função checkNumber que recebe um número inteiro e o verifica em relação a três critérios:

  • O número é positivo?
  • O número é par?
  • Esse número é divisível por 10?

A função deve retornar um array de valores booleanos (true e false) que representam os resultados dessas verificações.
