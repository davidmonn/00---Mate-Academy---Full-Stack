Como resultado, podemos observar que o primeiro tem um array vazio; isso ocorre pois os valores são atribuídos a a e b, restando nada para o rest. Quando queremos escrever uma função que aceita qualquer número de parâmetros, podemos ignorar a e b removendo-os e atribuir apenas nosso rest operator com um nome para essa variável (neste caso, chamamos de args).
