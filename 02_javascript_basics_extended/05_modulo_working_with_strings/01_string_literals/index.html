Template String/Interpolacao

Usamos o Template String ou Interpolacao para podermos adicionar/injetar valore sem precisarmos usar a contacatenacao.

Como usar

Para podermos usar o Template String basta usarmos o acento invertido (``) com ele conseguimos adicionar variaveis dentro de nossa string.
