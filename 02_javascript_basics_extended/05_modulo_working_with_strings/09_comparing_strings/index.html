Comparing strings

Intro

Agora iremos aprender mais um pouco sobre comparacao de strings.

Exemplo

Para isso teremos o seguinte codigo como exemplo:

Temos duas variaveis ambas com nomes atribuidos, apos isso em nosso primeiro console.log estamos imprimindo ambos nomes e se o nome1 e > nome2. Nessa comparacao feita entre variaveis dentro do console tera como resultado true pois o nome1 é maior que o nome2

Ja no segundo treco de codigo, estamos imprimindo no console o primeiro caractere de cada um dos nomes e o codigo de cada um desses caracteres. No JS quando fazemos comparacao de string, oque o JS faz e comparar letra por letra, mas oque realmente e comparado e o codigo daquela letra.

Um exemplo seria se ambos os nome1 e nome2, comecassem com as mesmas letras, o JS iria para a proxima para comparar, e ele vai fazendo isso ate encontrar valores diferentes e chagar a conclusao de qual e maior.

Porem temos um problema, se fizermos por exemplo uma comparacao desses ambos nomes se acabarmos mudando a letra do primeiro ou segundo para minusculo o resultado pode acabar sendo alterado, isso pois cada caractere tem um valor e maiusculo e minusculo tambem tem diferentes valores. Para evitarmos esse tipo de sistuacoes de comparacoes de strings, o que podemos fazer para resolver e fazer uma comparacao justa é podermos fazer antes da comparacao, converter ambas varaiveis para toLowerCase assim teremos ambas da mesma forma de caracteres e nao teremos resultado inesperados. Tem alguns casos onde por exemplo em portugues que temos caracteres especiais, um exemplo seria ç e ã.

localeCompare

Nesses casos podemos fazer uso do metodo localeCompare, que ira retornar 1 se o nome na comparacao seja maior que o outro e -1 se essa comparacao retornar false.
