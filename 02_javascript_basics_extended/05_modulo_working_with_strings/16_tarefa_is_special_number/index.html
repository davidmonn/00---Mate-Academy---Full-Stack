Is special number

Intro

Crie a função isSpecialNumber que aceita um número positivo - n e determina se ele é especial.

Um número é considerado especial se cada um dos seus dígitos não for maior que 5 (0, 1, 2, 3, 4 or 5).

A função deve retornar a string 'Special!!' se o número for especial, e 'NOT!!' caso contrário.
