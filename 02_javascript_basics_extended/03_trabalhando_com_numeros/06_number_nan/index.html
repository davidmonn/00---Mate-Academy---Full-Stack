Number NaN

Intro

NaN

NaN (Not a Number): acotece em alguns casos como por exemplo 0/0 como resultado teremos NaN no caso (nao e um numero). Isso tambem pode ocorrer quando tentamos fazer uma divisao com uma string. Mas coisas como: 0 / '10' que no caso o 10 foi passado como uma string podemos obter o resultado de 0. Isso ocorre porque o JS é uma linguagem não tipada.

Essa fraqueza na tipagem de dados faz com que possamos utilizar na mesma expressao numeros e strings e caso a string contenha numeros, ele ira fazer uma conversao e executar a operacao.

Verificando NaN

Temos uma funcao para podermos checar se um valor e NaN sendo ele: isNaN(x);.
