Tarefa: Get Speed Statistic

Intro

A primeira leva de robôs está pronta. Agora eles precisam ser testados. Todos os robôs são únicos e cada um tem sua própria velocidade. Nesta tarefa, você precisa encontrar a velocidade mínima, máxima e média dos robôs.

Implemente a função getSpeedStatistic que aceita o array testResults das velocidades dos robôs e retorna as estatísticas como um array com 3 números:

  • o primeiro é a velocidade mínima;
  • o segundo é a velocidade máxima;
  • o último é a velocidade média, arredondada para baixo (use Math.floor).

Observe: se o array testResults estiver vazio, retorne [0, 0, 0].
