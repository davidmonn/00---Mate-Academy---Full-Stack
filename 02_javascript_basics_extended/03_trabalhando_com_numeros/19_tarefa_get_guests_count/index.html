Tarefa: Get Guests Count

Intro

O ramo de hotelaria não é fácil. O Grand Mate Hotel atualizou seu site para reserva de quartos. Além do número de telefone do hotel, agora há também um formulário de reserva.

O formulário de reserva exige o número de hóspedes, mas infelizmente os programadores fizeram esse input tipo texto e agora o hotel obtém resultados do formulário como "1 hóspede", "3", "Eu e meu amor", "Dois hóspedes", " Talvez 6".

Vamos melhorar o software do hotel e escrever rapidamente a primeira versão da função getGuestsCount para eles, que pegará a string guestsInput e retornará o número de hóspedes somente se o número estiver no início da string. Caso contrário, será retornada a string not a number.

Exemplos

  • getGuestsCount('Two') === 'not a number'
  • getGuestsCount('I'll 1') === 'not a number'
  • getGuestsCount('3 people') === 3
