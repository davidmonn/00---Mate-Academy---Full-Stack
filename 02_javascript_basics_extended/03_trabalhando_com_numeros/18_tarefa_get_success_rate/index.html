Tarefa: Get Success Rate

Intro

Agora, você encontrará a porcentagem de ocorrência de um caractere em uma string.

Melhoramos nosso programa para coletar estatísticas dos webinars do Misha. Após coletar as estatísticas, ele envia os dados para o servidor na forma de uma string 111001010111011, onde 1 é o aluno que entendeu o tópico, e 0, infelizmente, não entendeu.

Mas seria útil entender a porcentagem de estudantes que aprenderam o material, pois isso mostrará o quão eficaz foi o webinar.

Crie a função getSuccessRate que aceita a string statistic e retorna a porcentagem de estudantes que entenderam o material.

Observe: se a string de entrada estiver vazia, retorne 0.
