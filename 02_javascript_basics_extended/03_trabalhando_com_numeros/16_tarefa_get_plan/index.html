Tarefa: Get Plan

Intro

Chegou a hora de aumentar a nossa produção de robôs! Implemente a função getPlan que recebe 3 argumentos:

  • startProduction — o número de robôs que produzimos atualmente por mês;
  • numberOfMonths — o número de meses para o aumento da produção;
  • percent — o aumento percentual esperado na produção a cada mês.

A função deve retornar um array com as metas para o número de robôs para o numberOfMonth fornecido.

Para entender como isso funciona, vejamos um exemplo. Digamos que temos

startProduction = 200, numberOfMonths = 3 e percent = 50:

  • a primeira meta é 200 + 50% = 300 robôs;
  • a segunda é 300 + 50% = 450 robôs;
  • e a terceira é 450 + 50% = 675 robôs.

O array resultante é [300, 450, 675].
