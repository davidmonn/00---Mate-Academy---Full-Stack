Math

Intro

Com esse metodo temos diversas utilidade, aqui veremos as principais.

Math

O Math no JavaScript é um objeto nativo que contém várias funções matemáticas prontas para uso. Ele não precisa ser criado, basta utilizá-lo escrevendo Math. seguido do nome da função.

Math.ceil()

que serve para arredondar um número sempre para cima. Isso significa que, mesmo que o número tenha uma pequena parte decimal, ele será aumentado para o próximo número inteiro. Por exemplo, 18.01 se torna 19, enquanto 18 continua sendo 18.

Math.floor

Math.floor, que faz o oposto: arredonda o número sempre para baixo. Ou seja, qualquer valor decimal é simplesmente descartado. Por exemplo, 18.9 se torna 18.

Math.random

Math.round realiza o arredondamento comum, aquele que estamos acostumados na matemática. Se a parte decimal for 0.5 ou maior, ele arredonda para cima; caso contrário, arredonda para baixo.

Math.max() e Math.min()

Math.max e Math.min servem para encontrar, respectivamente, o maior e o menor valor entre vários números informados. Por exemplo, ao passar vários valores para Math.max, ele retornará apenas o maior deles.

Resumo:

  • ceil → arredonda para cima
  • floor → arredonda para baixo
  • round → arredonda
  • random → aleatório
  • max/min → maior/menor
  • pow → potência
  • sqrt → raiz
  • abs → positivo
