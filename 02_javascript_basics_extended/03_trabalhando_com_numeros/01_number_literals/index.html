Numbers Literals

Intro

Um conceito muito importante é que temos diveras maneiras de se considerar é que em JS temos diveras maneiras de representar numeros.

Inteiros

Ex: let x1 = 42;

Base 2

Ex: let x2 = 0b101010;

Base 8

Ex: let x3 = 0o52;

Hexadecimal

Ex: let x4 = 0x2A;

Ex: let x5 = 0x2a;

Outras Representacoes:

Float

Ex: let y1 = 42.000

Ex: let y2 = 42.;

Ex: let y3 = 0.42e2;

Ex: let y4 = .42e2;

Ex: let y5 = 4200e-3;
