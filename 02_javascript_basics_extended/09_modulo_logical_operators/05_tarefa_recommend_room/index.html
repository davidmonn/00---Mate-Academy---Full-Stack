Tarefa: Recommend Room

Intro

Recentemente foi construído um novo edifício com quartos de 4 camas no Grand Mate Hotel. Os proprietários novamente nos procuraram em busca de ajuda.

Você precisa criar uma função recommendRoom para o site que irá automaticamente recomendar o quarto de acordo com os parâmetros inseridos adultsCount, childrenCount, babiesCount.

Existem dois tipos de quartos:

  • small room para até 4 pessoas
  • big room para até 8 pessoas

Não se esqueça da opção extra bed para bebês. Ela está disponível para quartos para 4 pessoas e para quartos para 8 pessoas.

Não se preocupe com a validade dos dados, o validador de função canTheyBook já os verificou. Basta retornar a string correta para os parâmetros fornecidos.
