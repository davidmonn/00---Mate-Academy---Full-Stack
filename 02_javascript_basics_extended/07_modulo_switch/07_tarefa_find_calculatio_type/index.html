Find calculation type

Intro

Você precisa criar uma função findCalculationType que recebe 3 argumentos: 2 números e o resultado de uma operação desconhecida realizada neles (também um número).

Com base nesses 3 valores você deve retornar uma string que descreve qual operação foi usada para obter o resultado fornecido.

As strings de retorno possíveis são: addition, subtraction, multiplication, division.
