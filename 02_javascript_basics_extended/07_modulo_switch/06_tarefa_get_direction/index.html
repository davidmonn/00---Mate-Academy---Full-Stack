Tarefa: Get Direction

Intro

Na academia Mate treinamos não só pessoas, como também robôs. Ensinar robôs é ainda mais difícil do que ensinar pessoas!

Nosso robô recebe um comando em seu terminal na forma da string back, forward, left, right, stop. Em seguida, seu cérebro converte o valor em coordenadas x e y e envia um impulso com coordenadas para suas pernas robóticas como uma string hor=x ver=y.

Escreva uma função getDirection, que recebe uma string direction com direção e retorna uma string no formato hor=x ver=y.

Os comandos são os seguintes:

  • forward é o sinal 0 para x e 1 para y
  • back é o sinal 0 para x e -1 para y
  • right é o sinal 1 para x e 0 para y
  • left é o sinal -1 para x e 0 para y
  • stop é o sinal 0 para x e 0 para y

Se o comando não for reconhecido, x e y serão definidos como 0.

Por exemplo:

  • Para o comando 'forward' o robô precisa de coordenadas no formato hor=0 ver=1
  • E ele não conhece o comando 'turn around', por isso as coordenadas serão hor=0 ver=0
