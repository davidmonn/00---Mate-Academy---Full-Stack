Codigo Legivel

Quando estamos escrevendo um codigo, estamos sempre escrevendo algo para que outra pessoa consiga entender. Qualquer codigo é entendiivel por uma maquina, onde ira pegar nosso codigo e executa-lo. Porem devemos sempre nos lembrar que estamos sempre trabalhando em um time onde alguem ira precisar entender nosso codigo para tambem fazer alteracoes.

Se um codigo nao e auto-explicativo, pode acabar ficando ruim ate mesmo para nos mesmos conseguirmos entender o codigo, caso precisemos fazer algum tipo de alteracao.
