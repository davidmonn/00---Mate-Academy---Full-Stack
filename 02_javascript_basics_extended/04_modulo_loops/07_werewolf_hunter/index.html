Werewolf Hunter

Intro

Nesta tarefa, você aprenderá a "reverter" uma string e remover caracteres desnecessários.

Crie a função isWerewolf que aceita a string target e retorna true se for um lobisomem ou false se não for.

Um lobisomem é uma palavra ou sentença que pode ser lida da mesma forma em ambas as direções (da esquerda para a direita e vice-versa), ignorando maiúsculas/minúsculas, espaços e pontuação.
