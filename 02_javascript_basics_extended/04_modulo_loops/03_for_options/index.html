For Option

Intro

Entendendo melhor o laco de repeticao.

Explicacao

  • 1) Primeiro parametro de nossa estrutura for sendo ele, exemplo: let i = 0; sendo ele de onde queremos comecar.
  • 2) Condicao: i <= 3; que sera avaliada em cada iteracao (cada vez que for passando por ele novamente para saber quando se deve parar).
  • 3) i++ nosso "passo", como a variavel por qual estamos iterando vai ser alterada.
