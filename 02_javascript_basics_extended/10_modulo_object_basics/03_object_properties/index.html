Object Properties

Intro

Aqui iremos continuar nos aprofundando em objetos.

Codigo de Exemplo:

Quando temos um objeto, em algum momento precisaremos acessar as propriedades desse objeto.

No JS temos duas menairas de acessar essas propriedades.

  • 1) Notacao de Ponto: nome do objeto + ponto (.), depois nome da propriedade que queremos acessar.
    • Ex: user.nome
  • 2) Notacao de Colchete: usamos o nome do objeto + nome da propriedade que desejamos acessar dentro de colchetes como sring ('').
    • Ex: user['sobrenome'].
