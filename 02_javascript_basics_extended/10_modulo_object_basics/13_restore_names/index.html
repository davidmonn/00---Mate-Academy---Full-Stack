Tarefa: Restore Names

Intro

O banco de dados falhou. Alguns usuários perderam valores do campo firstName, mas o objeto user possui um campo fullName, por isso podemos recuperar o firstName.

Implemente a função restoreNames que recebe um array de users e define firstName corretos para usuários que não o possuem ou que constem como undefined. Você não deve retornar nada da função.
