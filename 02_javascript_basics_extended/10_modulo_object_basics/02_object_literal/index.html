Objetos

Definimos objetos basicamente uma colecao de dados contidas em pares chave e valor/

Codigo de Exemplo:

Podemos observar que podemos declarar de diversas maneiras as chaves de nosso objeto. Onde por exemplo deixamos as chaves em forma de string 'nome' tambem declaramos chave sobrenome com aspas duplas "" e tambem declaramos o nomeCompleto sem aspas.

Outra meneira de declarar propriedades em nosso objeto é com expressao como 'e' + 'cassado'.

Quando temos uma expressao na delcaracao da chave em nosso objeto precisamos usar colchetes ([]).

Para finalizar tambem temos nossa propriedade idade sem valor. Porem quando observamos em nosso console do navegador, podemos observar que la tem idade 28. Igual delcaramos em nossa variavel const idade = 28;.

Sendo assim nossa propriedade do objeto recebe o valor de idade de nossa varivel apenas omitimos. Ficaria basciamente algo como idad: idade.
