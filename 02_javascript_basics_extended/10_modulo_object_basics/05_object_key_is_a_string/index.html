Explicacao

Aqui podemos observar que declaramos um objeto chamado dados e declaramos algumas propriedades e tambem atribuimos alguns valores para essas propriedades. Por fim temos um comando para podermos imprimir em nosso console.

Em nosso console foi imprimido como resultado o valor de 400, todas as propriedades ficaram com esse valor.

Isso ocorre pois dentro do JS, quando declaramos uma chave, independente da maneira que a declararmos, a chave sempre sera uma string.

Como fizemos todas essas chaves de diferentes formas, o JS ve que essa chave ja existe e apenas sobreescreve os valores das chaves.
